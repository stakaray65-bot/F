# 题材正文提示卡

> 由第1章写前召回生成（主题材：快穿，置信度中；本书无对标）。只约束正文层的题材味，不改细纲剧情；本书「作者已定」与文风要求优先。

- 题材边界：快穿 + 系统 + 双女主 1v1 救赎；每个世界一个虐文模板，宿主附身进去改女主的命。
- 核心逻辑：原书压力 + 系统规则限制 + 当前世界人物的情绪；宿主知道剧情不等于躺赢，每次改写都带出新后果。
- 读者期待：看宿主嘴碎又利落地拆虐文套路；看女主一个世界比一个世界更不对劲地反向攻略她。
- 核心爽点/情绪：宿主替女主掀翻原书安排、原住民反应失衡；女主把这份好加倍还回来。系统反馈服务关系变化，不抢正文。
- 正文落点：开场落在原身困局与剧情节点前一刻；冲突落在身份限制和任务代价；结尾落在任务数值、角色态度偏移或系统破绽。
- 前中后期打法：世界开局快——身份、困局、任务、第一次反击尽量在前半章完成；世界中段放大感情与代价；世界尾快速结算并切女主视角留刀。
- 节奏密度：短段落、对话多；系统面板只保留目标、数值、风险，每次弹出不超过几行。
- 场景颗粒：先给身份牌、关系牌、任务牌和眼前麻烦，不急着铺完整世界观。
- 禁止漂移：不要每个世界开头模板化报剧情；不要让系统变成不停吐槽的客服旁白（它一本正经，笑点在宿主接话）；不要让宿主靠「知道原文」躺赢；原书受苦一两句带过，不正面铺陈。
- 本章取舍：每章在任务、关系、打脸里选一个主轴。
