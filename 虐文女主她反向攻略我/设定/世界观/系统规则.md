# 系统规则（金手指）

> 「已定」来自 `设定/题材定位.md`「作者已定」；「刻度」一节的候选还没定。

## 已定

- 宿主绑定「拯救虐文女主系统」，任务：让每个世界的虐文女主少吃苦、活下去。
- 苦难值 0–100，原书结局 = 100。
- 任务完成 = 苦难值降到 20 以下 且 女主活过原书死亡节点；完成后宿主 72 小时内脱离该世界。
- 违规给短时疼痛。
- 另有一项系统读不出、宿主看得见的异常数值，随碎片累积越来越清楚。
- 系统对宿主的说法：完成任务能赚很多钱，回现实就能用（幌子）。
- 系统只给信息和规则，不替宿主动手；不给道具。
- 系统是女声，编号 5468。
- 全书铁律：每个世界都救成功，不写女主死亡、碎片丢失。

## 可能 / 不可能

| 可能 | 不可能 |
|---|---|
| 系统显示原书结局（女主的默认命运）、当前苦难值、死亡节点倒计时 | 系统读女主的心思、预测女主会怎么对宿主 |
| 系统提供宿主所附身份的基础资料 | 系统出手改剧情、给宿主战力或道具开挂（不给道具，保持「靠宿主自己的判断拆虐点」） |
| 违规时疼痛，短时、不伤身 | 疼痛致残致死 |
| 72 小时脱离，到点强制 | 宿主自愿留下（终局前） |
| 异常数值宿主看得见 | 系统读出异常数值 |

## 作者已确认

1. **「原书」是什么**：各世界是真实平行世界，没有作者；系统所说的「原书」是它推算出的、这个世界的她默认会走的命运（系统按虐文的样子讲给宿主，方便她懂）。原剧情的「惯性」来自人的动机和处境，不是超自然的世界修正——压迫者必须有自己的逻辑，不能降智。
2. **苦难值读什么**：处境（外部伤害与风险）+ 女主自己的心结。所以拆掉外部虐点后，还要女主自己「放下」才能降到 20 以下——这给每个世界的感情戏留了收尾位置。
3. **拖任务（世界4 起）**：因为苦难值含心结，女主可以靠「不肯说自己好了」「留一个心事不放」把苦难值稳在 21 左右，不伤身、不碰自残红线；宿主看得见数字卡住，却搞不懂为什么。
4. **违规清单（候选）**：向原住民暴露系统或穿越事实；主动伤害无关原住民；试图在 72 小时后滞留。
5. **任务失败**：对宿主说「扣报酬」；真实后果是那块碎片永远没了。全书不写失败（铁律，见读者契约·利益安全线）。

## 刻度（作者已定）

- **任务世界总数**：不告诉宿主。

- **报酬计价（经济锚点）**
  - 按苦难值降幅计件：每降 1 点记 1 万，面板实时跳数，宿主边救边算；一个世界（100 降到 20 以下）约 80 万。
  - 任务失败对宿主说「扣报酬」。
- **违规疼痛档位**：只有一档，短时剧痛几秒，不伤身。
- **异常数值的形态（金手指上限相关）**
  - 数字 + 乱码标签并用：只有宿主看得见的数值随碎片涨（【作者真相】对应沈渡脑细胞的唤醒度）；标签是乱码，每收回一块碎片解出一两个字，最后拼出沈渡留给她的一句话。
- **72 小时内的节奏**：面板显示倒计时；不能提前离开，也不能滞留。

## 面板显示口径（排纲第1章增量，写了要报）

- 任务面板常驻四项：当前苦难值、死亡节点倒计时（天）、当前报酬（元，开局 0）、任务世界序号（只显示「第 1 个」，不显示总数）。
- 异常数值第1章首次弹出：一串乱码标签 + 数字「1」，浮在面板角落、不在任务清单里；系统答「该数值不归本系统监测」，说得太快。第17章、第44章各变一次，变化幅度 [待补充]。
- 系统给方案时带「建议方案」字样（第1章建议「温和劝说」），宿主可不采纳，不采纳不算违规。
- 72 小时脱离规则第3章才由系统提醒；第1章不讲。
