# 宁蘅（世界2 女主）

> 排纲第16-25章时建档（写了要报；名字按卷纲已定，细节按推荐定，作者可改）。标【作者真相】的终局前不让读者知道。

## 角色卡

- 姓名：宁蘅
- 性别：女
- 角色功能：世界2 女主（被救者 → 反向攻略者）；【作者真相】平行世界的沈渡，身上附着第二块碎片，带着第一块的模糊余温。
- 与主角关系：一见如故；第19章起守着青梧、黏着青梧；第21章装病留人守夜（不对劲第2格「装可怜小心机」跨格）；第23章看穿宿主布局、配合演戏；第25章装怕雷挤床。【第26章揭的动机】她装可怜，挑的都是青梧要被叫走、要吃亏的时候——是在护她，读者先当成留人。
- 身份：南楚公主，十七岁；生母是早逝的低位妃嫔，自小养在皇后名下。和亲原本该是皇后亲生的公主，临行换成了她——母国的弃子（第22章她自己说出）。
- 核心特质：人前装弱（低头、细声、发抖、一身药味）；人后极聪明、看得透局；对青梧说软话、做小动作。
- 心结（苦难值里的那一截）：母国要她当刀、敌国要她当祭品；从小被要求「像」皇后那个亲生女儿——没人站她这边，她也不信有人会为她本人留下。第33章才放下（L1-05 单元卡）。
- 外貌：身量小，圆脸，眼睛又大又黑，睫毛短而密；唇色浅，人前总抿着；右耳垂有个小缺口（幼时被耳坠扯过）；梳南楚的双环髻，入燕后被要求改北燕的高髻（第20章）。不笑时像受惊的雀儿，笑起来左边有个浅酒窝（只对青梧笑）。
- 标志动作：替青梧挑掉香菜（第19章，F04 再现，「你不吃这个」「没人」）；画海棠（第22章，F14）；学青梧掐指节数雷（第25章，F08 呼应）；人后叫青梧「姑姑」，声音和人前不一样。
- 人生线（L04）：第25章跟青梧学看账、打算盘（为第31-34章主持互市埋）；退婚、断母国、主持互市（第31-34章）。
- 碎片残留口径（终局底牌边界）：只到「梦见」「说不清」——第22章「梦里有人说我不用像谁」；不知道温棠是谁、不知道宿主从哪来。熟悉感比温棠更早、更强。
- 退场方式：第35章（世界2 末）宿主离开后继续自己的人生；该章女主视角只写碎片记得的零星片段。
