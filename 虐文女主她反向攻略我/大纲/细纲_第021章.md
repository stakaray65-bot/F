## 细纲（第 21 章）

### 第 21 章：这病挑时辰
- 核心事件：宁蘅连着三夜「头疼」「咳」，非要青梧守在内寝；孙嬷嬷要接手守夜，说「公主是个药罐子，离了奴婢活不过冬」，宁蘅攥着青梧的袖子不放。青梧发现药都倒进了窗下兰花盆、咳嗽只在她起身时才咳——「你这病，挑时辰」；宁蘅不认，小声问「那你还走吗」，她留下了。亥时面板突跳，苦难值 94→97，处境项「任务对象涉嫌通敌风险上升」；她想起那只沉得不对的十七号箱，拿钥匙去西厢量：外高一尺八，内深一尺四，差四寸——夹层里一封南楚火漆的密信，「交公主亲启」。她没烧，原样放回去当饵；回到内寝，宁蘅睁着眼：「起夜要带钥匙？」

- 目标情绪：读者先被宁蘅装病的小把戏和青梧一眼看穿逗乐，「那你还走吗」软得人心里一塌；亥时数字往上跳，笑意一下收住；量箱子、撬夹层，紧到屏住气；「交公主亲启」几个字一出，背后一凉——原书的死法就躺在这儿；她放回去那一下，读者跟着赌；最后宁蘅一句「起夜要带钥匙」，悬着的心又多了一层：这公主不简单。推进单元情绪引擎：本轮触发（苦难值夜里突跳＋嫁妆分量对不上）落地，宿主用上金手指新用法——苦难值实时波动当预警。
- 主角目标/关键选择：林迟要弄清楚苦难值为什么半夜往上涨，并找到能要公主命的那样东西。关键选择：密信在手里，烧掉最干脆、今晚就能睡个踏实觉；可烧了，放信的人会再放一封、或者干脆去告发，她连是谁都不知道。她选择原样放回去，记下火漆纹样，拿它当饵钓出放信的人。代价：那封能要公主命的信，今晚还在公主的嫁妆里，她得自己扛着这个险。
- 章首钩子：悬念对话开局 — 青梧刚抱起被褥要回后罩房，帐子里一声：「姑姑，我头疼。」
- 爽点：掉马甲（小）——青梧拆穿宁蘅装病（药倒花盆、咳嗽挑时辰）；目标达成（小）：量出差四寸、找到密信。往下看的理由：信是谁放的；宁蘅到底看见了多少。

#### 内容概括（五段式）
- 起因：入宫第六天，宁蘅开始夜夜「病」，非要青梧守在内寝；孙嬷嬷想把守夜攥回自己手里。
- 发展：孙嬷嬷捻着沉香珠进来要接手：「公主是个药罐子，离了奴婢活不过冬。」宁蘅咳得更厉害，手攥着青梧的袖子不放，孙嬷嬷只好退下。青梧坐在脚踏上，看见窗下兰花盆的土是湿的、一股苦药味；她一起身，帐子里就咳，她一坐下，就不咳了。「你这病，挑时辰。」宁蘅不认，把脸埋进被子，小声：「那你还走吗？」青梧没走。
- 转折：亥时，面板突跳：【当前苦难值：97】，系统：「处境项：任务对象涉嫌通敌风险上升。」林迟问「涨了扣钱吗」，系统「报酬不予扣除」；她再问是谁、在哪，系统不答。她想起宫门那天四个人抬得龇牙咧嘴的十七号箱。
- 高潮：她摸出掌簿钥匙去西厢库房，拿尺量十七号箱：外高一尺八，里头一掏到底只有一尺四，差四寸。她撬开底板，夹层里一封信，封口南楚内廷火漆，内页抄着北燕界河一线驻军数目，末尾四个字：「交公主亲启」。这就是原书里要她命的那样东西。她捏着信想烧，又停住——烧了，放信的人会再放、会去告发，她连人都找不着。她把信原样放回去，记下火漆纹，压好底板。
- 结尾：回到内寝，帐子里的人没睡，睁着眼看她：「姑姑去哪儿了？」「起夜。」宁蘅看着她手里那串钥匙：「起夜要带钥匙？」说完往里挪了挪，给她让出半边榻；窗外后罩房里，孙嬷嬷屋的灯还亮着。

#### 情节安排（多线）
- 主线推进：L01 找到原书「细作败露」的道具——十七号箱夹层密信；苦难值第一次在新世界回升（94→97）。
- 辅线推进：L02 从「你醒了」推到装病留人守夜——不对劲第2格「装可怜小心机」跨格；宁蘅第一次在青梧面前露出看得见东西的眼睛；L05 报酬回升不扣的规矩露面；L03 无（本章不动碎片线）。
- 事件线 / 任务线：装病 → 孙嬷嬷抢守夜 → 识破 → 「那你还走吗」→ 亥时突跳 → 量箱（卡出差四寸）→ 夹层密信 → 放回当饵 → 「起夜要带钥匙」。
- 感情线 / 关系线：试探阶段。宁蘅单方的小心机留人，林迟识破了还是留下（给回报）；她以为公主是怕生，慢半拍。
- 逻辑线：苦难值夜里上涨 → 想起箱子分量 → 量出夹层、找到密信 → 选择放回当饵 → 新问题：放信的人是谁；宁蘅看见了多少。

#### 人物关系和出场顺序
- 出场顺序：青梧（林迟）→ 宁蘅（帐中）→ 孙嬷嬷 → 兰花盆、药碗（关键物件）→ 系统面板 → 系统5468 → 西厢库房、十七号箱（关键物件）→ 尺 → 密信与火漆（关键物件）→ 宁蘅 → 后罩房的灯
- 人物关系变化：林迟×宁蘅：公主守过她 → 她识破公主装病、仍留下守夜；宁蘅×孙嬷嬷：主仆 → 宁蘅当着青梧的面不要她守夜；林迟×孙嬷嬷：被压一头 → 守夜的位置抢过来了。
- 视角/信息差：读者与林迟知道密信在十七号箱、已放回；宁蘅知道青梧夜里拿钥匙出去过，不知道去做什么（读者也不知道她猜到多少）；孙嬷嬷不知道密信已被发现。
