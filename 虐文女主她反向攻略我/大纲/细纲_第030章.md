## 细纲（第 30 章）

### 第 30 章：守夜不加钱
- 核心事件：秋狩前夜，猎苑营火一堆堆，青梧抱着要回来的小算盘守在公主帐门口，算这十六万怎么来的。宁蘅睡不着，挨着她坐，掐着指节数更鼓，问她早知不知道袖里是什么——「不知道，只知道是你的东西，你自己拿主意。」元昭夜里来到帐外，交代他的算盘：入燕当夜给漱玉轩加的侍卫，是看着也是护着；他早疑心公主无辜，可要暗线活着动才牵得出裴相，「本宫也拿公主钓过鱼」；大婚推迟，和约重谈，南楚那边会来人。子时更鼓一响，面板跳【死亡节点已度过】，苦难值52→35，报酬65万。天亮围猎号角，宁蘅靠着她醒过来：「姑姑，我不想嫁他。也回不去了。」

- 字数口径：visible_chars_v1
- 单元ID/位置：L1-05；单元第6拍「余波」；死亡节点平安度过
- 目标情绪：读者从「还剩一天」的悬着里进来，营火、更鼓，安静里绷着一根弦；林迟算账、宁蘅掐指节，松下来一点、甜一点；太子坦白「也拿公主钓过鱼」，读者从对他的戒备转成「这人坏得坦荡」，有点乐；子时一跳，长出一口气；35卡住、宁蘅那句「嫁不得、回不去」，轻松里留一个小缺口。推进单元情绪引擎：兑现后的低压承接——小而可见的收益（死亡节点过、报酬到账）接下一轮问题。
- 主角目标/关键选择：林迟要守过今夜，并弄清太子这个交易方往后靠不靠得住。关键选择：太子在帐外交底后问她「公主想要什么」，她可以替宁蘅开口（她心里有数：不嫁、要条活路），也能顺手替自己多要一笔；她选择不替宁蘅答，只说「公主想好了，自己会说」。代价：这一夜没给宁蘅多讨到一句保证。
- 章首钩子：意象预示 — 猎苑夜里营火一堆接一堆，风从山口灌下来，火苗都朝公主帐那边倒。
- 爽点：收获盘点（死亡节点度过、苦难值52→35、报酬48万→65万，林迟按历史最低值把账一笔笔对清）；太子坦白的态度转变。往下看的理由：35卡在哪；宁蘅「嫁不得、回不去」，她要去哪儿。
- 本章禁止提前释放：
  - 不提退婚、不提互市（第31章宁蘅自己提）；宁蘅只说「不想嫁、回不去」
  - 苦难值不降到20以下；宁蘅心结不放下（第33章）
  - 太子坦白只到「疑心公主无辜、留暗线钓裴相、不要裴家太子妃」，不写对公主有情

#### 内容概括（五段式）
- 起因：第29章裴相、韦从简落网，公主罪名摘掉，可面板上「死亡节点倒计时：1 天」还在——原书的秋狩前夜就是今晚。
- 发展：青梧要回了自己的小算盘，抱着坐在公主帐门口，按历史最低值算：90到52，只计68以下那十六点，十六万，合计四十八万。宁蘅睡不着，裹着披风挨着她坐，右手拇指掐着指节数更鼓。她问：「你早知道我袖里是什么？」「不知道。只知道是你的东西，你自己拿主意。」
- 转折：元昭来到帐外，屏退秦戈，交底：入燕那夜给漱玉轩加的侍卫是看着也是护着；侍卫回报公主从没和使团私下往来，他早疑心她无辜，可得让暗线活着动才能牵出裴相，「本宫也拿公主钓过鱼」；他要的是暗线落网、不要裴家太子妃。林迟嘴快：「那殿下也欠公主一笔。」太子说大婚推迟、和约重谈，南楚扣了正使，必会来人；问：「公主想要什么？」林迟不替她答：「公主想好了，自己会说。」
- 高潮：子时更鼓一响，面板先跳【死亡节点已度过】，再跳【当前苦难值：35】【当前报酬：650000 元】；系统：「处境项：任务对象婚约与归属未定。其余为任务对象自身状态，本系统不予解读。」
- 结尾：天亮围猎号角吹起来，宁蘅靠着她肩膀醒过来，手还攥着她的袖子，看着远处马队出苑：「姑姑，我不想嫁他。也回不去了。」

#### 情节安排（多线）
- 主线推进：L01 世界2 死亡节点平安度过；苦难值52→35；处境项只剩婚约与归属。
- 辅线推进：L05 守夜算账、65万（按历史最低值计件）；L02 「你自己拿主意」第二回落地，宁蘅掐指节数更鼓（跨世界小动作，F008 轻回）；L04 宁蘅第一次说出「不想嫁、回不去」，为第31章自己提退婚埋口子。
- 事件线 / 任务线：营火守夜 → 算账 → 宁蘅数更鼓、问袖里 → 太子交底 → 「公主想要什么」不替答 → 子时死亡节点度过 → 35 → 天亮号角 → 「不想嫁、回不去」。
- 感情线 / 关系线：试探阶段的低压糖：并肩守夜、靠肩睡着、攥袖子；林迟嘴上嫌守夜不加钱。不写心动独白。
- 逻辑线：裴相落网 → 原书那夜没人来赐死 → 死亡节点过、苦难值降 → 太子交底：他要的东西已到手，往后可谈 → 新问题：处境只剩婚约与归属，宁蘅嫁不得、回不去；35卡住。

#### 人物关系和出场顺序
- 出场顺序：猎苑营火（意象）→ 青梧（林迟）→ 小算盘（物件）→ 系统面板（报酬）→ 宁蘅 → 更鼓 → 元昭 → 秦戈（被屏退）→ 系统面板（零点）→ 围猎号角、马队
- 人物关系变化：林迟×元昭：交易方 → 交过底、可往来的中立方（她敢当面说「殿下也欠一笔」）；宁蘅×元昭：人质与太子 → 太子承认拿她钓过鱼；林迟×宁蘅：互为证人 → 守夜并肩，她第一次对林迟说出自己的处境。
- 视角/信息差：太子的旧算盘（F12）本章交底给读者与林迟；宁蘅心里那截心结仍不说；林迟看见35，知道还差一截，不知道卡在哪。
