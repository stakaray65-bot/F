## 细纲（第 17 章）

### 第 17 章：这顿我请，算模特费
- 核心事件：72 小时只剩最后十二个多小时，林迟照许知意的笔迹给原主留了一页备忘，压在抽屉里那封信上；两人去市美术馆看挂上墙的《指节》，温棠用金奖的钱请她吃了一碗面，说「这顿我请，算模特费」；最后一小时温棠攥着她的右手，学她的样子一节一节掐指节数分钟；倒计时归零，报酬 81 万入账，林迟后颈像被钉进一根钉子，右手抖得从温棠手里滑了出去，视野角落那个异常数值从 1 跳到 6，乱码里亮出了一个字：「活」。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-03；单元第5拍「余波」（72 小时最后一天、碎片收回）；本卷中点（第一次离开、异常数值第一次变化）
- 目标情绪：读者带着第16章的倒计时进来，前半章轻：林迟描「知」字描得龇牙咧嘴、系统一本正经地判「不构成违规」，美术馆里路人夸那只手画得像真的；一碗面「算模特费」把第12章的玩笑接回来，甜里发酸；最后一小时温棠数她的指节，读者跟着一分钟一分钟往下掉；归零那一下的剧痛和那个「活」字，让读者在告别的悲伤之外第一次觉得——这不只是穿越副作用。推进单元情绪引擎：兑现的代价落地（宿主必须走）；卷级中点转折。
- 主角目标/关键选择：林迟要用最后一天把该交代的交代完，让原主醒来不为难温棠，也让温棠这一天过得像平常。关键选择：她可以把最后一天全花在交代上（多留几张便利贴、多算几笔账），也可以陪温棠出门、什么正事都不干；她把备忘一早写完，剩下的时间全给温棠，跟她去看画、吃面，最后一小时不说话，把手交给她数。代价：留给自己的时间一分没有；离开那一下，她连「再见」都没说完。
- 章首钩子：倒计时开局 — 一睁眼，面板：【脱离倒计时：12:03:17】；前两天一句带过（温棠签了租约、搬了一半东西），今天是最后一天。
- 爽点：收获盘点（报酬 81 万入账）＋情感圆满（《指节》上墙，温棠请她吃面，把第12章「画我得收钱」接回来）；无打脸。往下看的理由：那一下剧痛不对劲；那个「活」字是什么；原主醒来，温棠怎么办。
- 本章禁止提前释放：
  - 碎片收回的真实含义：林迟只当是穿越副作用，正文不写「碎片」二字
  - 异常数值只变化不读懂：只亮出一个「活」字，不解释，林迟不猜
  - 林迟不对温棠说原主会不认识她、不说系统与穿越
  - 系统不催休息（第19章）
  - 不写肢体亲密超过握手；不写心动独白

#### 内容概括（五段式）
- 起因：第16章夜里任务完成，72 小时倒计时开始；这具身体的主人迟早会醒，林迟得给她、也给温棠留条路。
- 发展：一早林迟坐在书桌前，照着原主的笔迹写备忘：透析每周一次、婚约已解、冰箱上的电话、「温棠救过你的命，对她好一点」；「知」字最后一笔往上挑，她描了三遍。写完问 5468，系统：「未涉及系统与穿越事实，不构成违规。」她折好压在原主那封信上。上午两人去市美术馆，《指节》挂在一层展厅，展签上写着「温棠」；两个路人站在画前说「这手画得跟真的一样」，温棠在后头小声接了一句：「是真的。」
- 转折：中午温棠拉她进美院后街一家面馆，自己掏钱付账：「这顿我请，算模特费。」林迟愣了一下，想起第12章自己说的「画我得收钱」，低头吃面，一根香菜都没有——温棠点单时说了「不要香菜」。
- 高潮：夜里只剩最后一小时，温棠坐在她旁边，攥着她的右手，拇指一节一节掐她的指节，一分钟掐一下，掐完四个从头再来。最后十几秒，林迟说：「温棠，好好画。」后半句「画我得收钱，记账上」还没说完，倒计时归零——面板跳【脱离中】【世界1报酬：810000 元，已计入宿主账户】，后颈像被钉进一根钉子，剧痛，右手猛地一抖，从温棠手里滑了出去。
- 结尾：视野一点点白下去，角落里那串乱码跟着一跳，数字从 1 变成 6，乱码中间亮出一个能认的字——「活」；林迟最后看见的，是温棠还空攥着的那只手。

#### 情节安排（多线）
- 主线推进：L01 世界1 收束——72 小时走完，宿主脱离；卷级中点（第一次离开）。
- 辅线推进：L02 从「你会走吗」推到告别——温棠数她的指节，学走了她的动作（跨世界小动作的种子）；L03 第一次露面：碎片收回那一刻后颈剧痛、手抖（F09 埋），异常数值第一次变化（F01 付利息：1→6，解出「活」）；L05 报酬 81 万入账；L04《指节》上墙、温棠用自己的奖金请客。
- 事件线 / 任务线：写备忘 → 系统判不违规 → 美术馆看画 → 面馆「算模特费」→ 最后一小时数指节 → 归零 → 入账 → 剧痛 → 异常数值变化。
- 感情线 / 关系线：试探阶段的第一次告别。温棠攥手、数指节是依赖粘人的顶点；林迟把最后一天全给她，嘴上仍是「记账上」。不越过握手。
- 逻辑线：任务完成 → 72 小时到点 → 林迟交代后事、陪温棠过完最后一天 → 归零脱离 → 剧痛、异常数值变化（新问题：这一下疼是什么，那个字是什么，下一个世界在等）。

#### 人物关系和出场顺序
- 出场顺序：系统面板（倒计时）→ 林迟 → 温棠 → 书桌、原主那封信、备忘（关键物件）→ 系统5468 → 市美术馆展厅、《指节》与展签（关键物件）→ 两个路人观众 → 美院后街面馆 → 夜里的沙发 → 系统面板（脱离中、入账）→ 异常数值（关键物件）
- 人物关系变化：林迟×温棠：知道她会走 → 她走了，温棠手里空了；林迟×原主许知意：替她活了四十五天 → 把身体和一页备忘还给她；林迟×系统：雇主与打工人 → 第一次在交接时被「疼」了一下，系统没解释（第19章她才问）。
- 视角/信息差：读者与林迟看见「活」字，都不懂；读者开始怀疑剧痛不是普通副作用，林迟没往深处想；温棠只知道她要走，不知道这具身体的主人醒来不认识她。
