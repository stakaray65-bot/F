## 细纲（第 31 章）

### 第 31 章：一年顶两个太子妃
- 核心事件：秋狩还都，燕都照旧例开三夜灯市。宁蘅头一回出宫看灯，要一盏兔子灯，青梧把八十文砍到五十，嘀咕「陪看灯不在任务清单上，这得加钱」，宁蘅停住脚：「这句话，我好像听过。」次日礼部衙署重谈和约，南楚副使提婚期改十月十九、其余照旧；宁蘅自己站起来：「这门亲，我不结了。」礼部尚书问无婚何以为信，她拿学来的账摆出界河临渡互市——南茶北马，每月两市，什一抽税，首年两国各得税银约五千四百两，「我是南楚的公主，住在北燕，两边都得认我」。元昭准了退婚，准设临渡互市、由公主主持，写进新和约。苦难值35→28。副使脸色铁青：「此事须奏皇后娘娘。」

- 目标情绪：读者从猎苑守夜的松弛里进来，看灯会、砍价、兔子灯，轻快；「这得加钱」那句被宁蘅认出耳熟，甜里一丝发酸；谈判桌上一屋子人替她安排婚期，读者憋一下；她自己站起来说「不结了」，再把账一笔笔摆出来，读者跟着青梧在后排暗爽——这回出声的是她，不是姑姑。推进单元情绪引擎：本轮触发——新和约谈判；兑现的第一步——退婚与互市是宁蘅自己的选择和才能。
- 主角目标/关键选择：林迟要给宁蘅铺一条嫁不得、回不去之外的路。关键选择：谈判桌上她手里有现成的账，可以替宁蘅开口，把互市讲得更圆；她选择坐在后排一个字不说，只在宁蘅停顿时把算盘推过去。代价：宁蘅讲得磕绊、礼部尚书刁难，她得忍着看。
- 章首钩子：反差场景 — 四天前她坐着囚车上西山，今夜燕都坊市灯挂满了街，她手里拎着一盏兔子灯。
- 爽点：目标达成（退婚、互市写进新和约）+ 态度转变（礼部尚书与副使从安排她到听她算）；宁蘅「点石成金」的才能第一次当众露出来。往下看的理由：副使要奏皇后，南楚会怎么来要人。

#### 内容概括（五段式）
- 起因：第30章宁蘅说出「不想嫁、也回不去」；还都后大婚推迟、和约重谈，太子准公主出宫走动。
- 发展：秋狩还都，燕都照旧例开三夜灯市、解宵禁。宁蘅头一回出宫，秦戈远远跟着。她看中一盏兔子灯，摊主要八十文，青梧砍到五十，嘀咕：「陪看灯不在任务清单上，这得加钱。」宁蘅停住：「这句话，我好像听过。」「我天天说。」「不是。更早。」她说不清。灯下她掐着指节问燕都的茶价、马价，青梧随口答。
- 转折：次日礼部衙署重谈和约。元昭、礼部尚书在上首，南楚副使对面；青梧以掌簿坐后排。副使提婚期改十月十九、嫁妆婚仪照旧，满桌人替她排日子。宁蘅站起来：「这门亲，我不结了。」
- 高潮：礼部尚书问：「无婚何以为信？」宁蘅摆账：界河临渡开互市，南茶北马，逢初一、十五开市，什一抽税；按每市茶两万斤、马五十匹算，首年茶税七千二百两、马税三千六百两，合一万八百两，两国对分各五千四百两；「互市要一个两边都认的人。我是南楚的公主，住在北燕。」她算到一半卡壳，青梧把算盘推过去，她接着拨完。元昭：「准。婚约作罢；临渡互市，由公主主持，写进新和约。」面板：【当前苦难值：28】【当前报酬：720000 元】。
- 结尾：散了议，南楚副使收起文书，铁青着脸对宁蘅一揖：「此事，须奏皇后娘娘。」出了衙署，宁蘅回头看青梧，青梧在心里把那五千四百两跟太子妃月例一比——一年顶两个太子妃还多。

#### 情节安排（多线）
- 主线推进：L01 婚约这一项处境解除；苦难值35→28；新和约写进互市。
- 辅线推进：L04 从学账推到当众主持互市的提案与获准（退婚落地）；L03 「这得加钱」被宁蘅认出「更早听过」（碎片余温，只到说不清）；L05 林迟心里拿太子妃月例给互市税银标价。
- 事件线 / 任务线：灯市 → 兔子灯砍价 → 「这得加钱」耳熟 → 问茶价马价 → 衙署谈判 → 副使排婚期 → 「不结了」→ 尚书刁难 → 互市账 → 卡壳、推算盘 → 太子准 → 28 → 副使「须奏皇后」。卡点：尚书「无婚何以为信」——卡出宁蘅自己拿出互市。
- 感情线 / 关系线：试探阶段的糖：看灯、砍价、兔子灯；谈判桌上的「推算盘」是默契小动作。不写牵手。
- 逻辑线：嫁不得回不去 → 灯下问价是在攒底 → 退婚须有替代的信物 → 互市让她成为两边都要的人 → 太子本就不要这门亲，准 → 新问题：南楚皇后不会认。

#### 人物关系和出场顺序
- 出场顺序：燕都灯市（场景）→ 宁蘅 → 青梧（林迟）→ 秦戈（远处）→ 兔子灯摊主（路人）→ 兔子灯（物件）→ 礼部衙署 → 元昭 → 礼部尚书（路人）→ 南楚副使（路人）→ 小算盘（物件）→ 系统面板 → 新和约（关键物件）
- 人物关系变化：宁蘅×元昭：有婚约的人质 → 退婚，转为互市的合作方（元昭本卷退场转背景）；宁蘅×南楚：被安排婚期的公主 → 当着副使自己拒婚，母国「须奏娘娘」；林迟×宁蘅：替她出声的姑姑 → 坐后排推算盘的人。
- 视角/信息差：读者知道「这得加钱」温棠记得、宁蘅耳熟是碎片余温；林迟与宁蘅都不知道。读者与林迟知道28离20还差一截。
