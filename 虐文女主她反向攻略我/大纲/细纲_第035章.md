## 细纲（第 35 章）

### 第 35 章：醒来的姑姑不掐指节
- 核心事件：（宁蘅视角）那只手从她手里抖出去，姑姑靠着栏杆睡沉了，叫不醒。宁蘅把人扶回楼下偏间，守了一夜——跟入燕那年守着落水的青梧一样。天亮醒来的人跪起身叫她「殿下」，一口南楚宫腔，读着桌上那叠交接清单：「这是奴婢的字……可奴婢不记得写过。」她打算盘对互市账，珠子拨得规规矩矩，拇指一回也没往指节上去。宁蘅知道，那个人不是她。她拼命去想那个人，只剩一只掐指节的手、一句「这得加钱」、一句「我在这儿一天，就管你一天」、一声「会」——还有梦里那句「你不用像谁」，原来是同一个声音。醒来的青梧问往后听殿下吩咐，宁蘅说：「你自己想。」半个月后第二次开市，宁蘅不拨算盘，拿拇指掐着指节数船，在新账扉页写下一行：「下一次，我想早一点认出你。」
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-06；单元第5拍「女主视角」；世界2 最后一章、第一卷卷末
- 目标情绪：读者从系统空间那个「替」字和不散的疼里出来，换到宁蘅这边，先是守夜的不安；醒来的人叫「殿下」，读者知道答案、宁蘅不知道，刀从信息差里进去；算盘拨得规矩、拇指不往指节上去，读者比宁蘅先懂；「那个人不是她」落地时心里一酸；梦里那句话和那声「会」对上同一个声音，酸里一阵发麻；她让醒来的人「你自己想」，是她往前走了一步；最后那行字，悲里回温，留一口期待。推进单元情绪引擎：兑现之后的代价落在女主那边——被珍视过，说不清被谁；卷末钩子交给卷2。
- 主角目标/关键选择：（本章主视角为宁蘅）宁蘅要弄明白那个人去哪了，也要接着把自己的路走下去。关键选择：醒来的青梧说「往后都听殿下吩咐」，她可以把这个人留在身边当影子，照着那个人的样子用；她选择不，叫她「你自己想」，回不回南楚由她。代价：她亲手放走了身边最后一个和「那个人」长着同一张脸的人。
- 章首钩子：未完成动作开局 — 她的拇指还停在姑姑的一个指节上，可那只手已经不在她手里了；天黑没数完。
- 爽点：无显性爽点，功能是世界2 收刀、女主视角兑付「救了她就得走」第二次、给卷2 立期待；往下看的理由：她说「下一次」，下一个世界的「她」会不会更早认出那个人。
- 本章禁止提前释放：
  - 宁蘅视角只写碎片记得的零星片段（掐指节的手、「这得加钱」、「我在这儿一天，就管你一天」、「会」、梦里「你不用像谁」），不出现青梅、未来、救生舱、沈渡之名，不出现温棠与世界1 的具体人事
  - 宁蘅不知道系统、穿越；只到「那个人不是她」「说不清」；「下一次」是她说不清来由的念头，不得写成她知道有下一个世界
  - 原主青梧不记得这一个多月，不记起任何片段
  - 不切林迟视角、不切系统空间

#### 内容概括（五段式）
- 起因：第34章倒计时归零，那只手在宁蘅手里一抖、滑了出去；身边的人靠着栏杆睡沉，呼吸匀，叫不醒。
- 发展：宁蘅和杏儿把人扶回楼下偏间，她守了一夜，像七月底刚渡河时守着落水高烧的青梧一样坐在床边。天亮床上的人醒了，看见她慌忙跪起：「殿下。」一口南楚宫腔，规规矩矩。案上那叠交接清单她一张张读：「这是奴婢的字……可奴婢不记得写过。」读到「公主自己会算账，别替她算」，抬头看宁蘅，不明所以。
- 转折：醒来的青梧照清单去对互市账，打算盘拨得规规矩矩，拇指一回也没往指节上去；对完了也不说一句这得多少钱。宁蘅看着那双大手——同一双手——心里冒出一句：那个人，不是她。
- 高潮：宁蘅拼命想那个人的脸，想出来的都是青梧的脸，可这张脸不会眯着眼算炭钱；她记得每一件事，那个人在里头只剩一只掐指节的手、一句「这得加钱」、一句「我在这儿一天，就管你一天」、一声「会」。再往远处想，是那个说不清的梦——「你不用像谁」——她这才发现，梦里那个声音和说「会」的声音，是同一个。
- 结尾：醒来的青梧说往后都听殿下吩咐，宁蘅说：「你自己想。回不回南楚，你自己想。」半个月后十月十五第二次开市，她坐在棚下不拨算盘，拿右手拇指一节一节掐着指节数靠岸的船；数完，在新账扉页写下一行：「下一次，我想早一点认出你。」

#### 情节安排（多线）
- 主线推进：L01 世界2 收束——宿主已离开，原主醒来，女主活着、走在自己的路上。
- 辅线推进：L03 女主视角零星片段第二次兑现（F023 回收：梦里「你不用像谁」与「会」是同一个声音；跨世界掐指节）；L02 第二次告别的余波——「救了她就得走」第二次兑付，比第一次更早认出、更难放手；L04 宁蘅主持第二次开市。
- 事件线 / 任务线：手抖出去 → 叫不醒 → 扶回偏间守夜 → 醒来叫「殿下」→ 读清单 → 对账不掐指节 → 「那个人不是她」→ 想不起脸、只剩几样 → 梦与「会」同一个声音 → 「你自己想」→ 半月后开市 → 掐指节数船 → 扉页一行。
- 感情线 / 关系线：试探阶段的一次断开；宁蘅对「那个人」的怀念说不清对象，不写告白、不写「我喜欢她」。
- 逻辑线：宿主脱离 → 原主醒来不认识这一个多月 → 宁蘅从算盘与拇指认出「不是她」→ 她不把原主当影子留下，让她自己选 → 结果：她活着、主持互市，记得一个说不清的人，想早一点认出她（交卷2）。

#### 人物关系和出场顺序
- 出场顺序：宁蘅（视角）→ 空了的手 → 栏杆边睡着的青梧 → 杏儿（路人）→ 临渡驿楼下偏间 → 青梧（原主）醒来 → 交接清单（关键物件）→ 算盘、互市账（物件）→ 半月后临渡互市、靠岸的船 → 新账扉页（关键物件）
- 人物关系变化：宁蘅×原主青梧：同一张脸 → 客客气气的主仆，再到「你自己想」；宁蘅×「那个人」：天天在一起 → 只剩几样记得的东西和一个声音；宁蘅×自己：照着谁活的替嫁公主 → 自己数船、自己记账的互市主事。
- 视角/信息差：读者知道「那个人」是林迟、去了下一个世界，宁蘅不知道；读者知道梦里那句话是林迟在世界1 对温棠说的，宁蘅只觉得是同一个声音；原主什么都不知道。
