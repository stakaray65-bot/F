## 细纲（第 24 章）

### 第 24 章：奉太子令，搜
- 核心事件：东宫晾了一天，第二天一早秦戈领东宫卫围了漱玉轩，元昭亲自坐在廊下；孙嬷嬷跪着说公主妆奁里藏着南楚来的信。宁蘅人前抖成一团。秦戈从妆奁夹层里搜出来的却是一本账——孙嬷嬷的笔迹，三笔「收韦大人银」。孙嬷嬷喊栽赃，青梧出列，翻开掌簿册把三笔日子一笔笔对上：七月十九那晚孙嬷嬷去使团领过路费，七月廿七、八月初二她两回出轩采买，宫门簿上都有。宁蘅轻声对孙嬷嬷说：「嬷嬷说我离了你活不过冬——我试试。」孙嬷嬷被押入慎刑司，苦难值 93→68，报酬 32 万。元昭临走停在青梧面前：「你一个掌簿，倒知道该站在哪儿。」夜里，一骑驿马闯进宫门。

- 主角目标/关键选择：林迟要让这次搜宫只搜出孙嬷嬷，让公主干干净净站着。关键选择：搜出账之后，她可以缩在后头让东宫自己去查——女官出头，太子一定会注意到她；不出头，孙嬷嬷一口咬定是栽赃，账就成了一笔糊涂账，公主也洗不干净。她选择当众出列对账。代价：太子从此盯上了她。
- 章首钩子：悬念对话开局 — 一早院门被拍响，秦戈的声音：「奉太子令，搜。」
- 爽点：打脸（对称）＋慧眼识真＋收获盘点——孙嬷嬷「活不过冬」被宁蘅当面一句「我试试」顶回去，搜出来的是她自己的账；青梧当众对日子；苦难值 93→68，报酬 7 万→32 万，一口气二十五万。往下看的理由：太子盯上了这个女官；驿马带来的是什么。

#### 内容概括（五段式）
- 起因：第23章孙嬷嬷连夜去东宫告发；东宫晾了一天，按兵不动。
- 发展：第二天一早秦戈领东宫卫围了漱玉轩，元昭亲自来了，坐在廊下转扳指。孙嬷嬷当着太子跪下：「老奴不敢再瞒，公主妆奁里藏着南楚来的信。」宁蘅人前抖成一团，抓着青梧的袖子。秦戈进内寝搬出描金妆奁，一层层抽开，按开最底层的夹层。
- 转折：夹层里没有信，是一本薄账。秦戈呈给元昭，元昭翻开，念出声：「七月十九，收韦大人银五百两。」孙嬷嬷脸一下白了：「这不是老奴的——是有人栽赃！」
- 高潮：青梧出列，跪下行礼，翻开掌簿册：「奴婢管着轩里的支用账，请殿下对一对。」七月十九，送亲队伍驻界河南岸，那晚孙嬷嬷去使团领过公主的路费；七月廿七、八月初二，孙嬷嬷两回出轩采买，宫门簿上都记着时辰——账上三笔，一笔不差。宁蘅这时抬起头，声音还是细细的，对着孙嬷嬷说：「嬷嬷说我离了你活不过冬——我试试。」
- 结尾：元昭合上账：「押去慎刑司。南楚使臣那边，本宫自会问。」面板：【当前苦难值：68】【当前报酬：320000 元】。他起身走到院门，在青梧面前停住，看了她很久：「你一个掌簿，倒知道该站在哪儿。」夜里青梧在东耳房听见宫门方向马蹄急响，一骑驿马闯进了宫城。

#### 情节安排（多线）
- 主线推进：L01 世界2 第一个压迫者落网（孙嬷嬷），细作道具拆除第一层，公主洗清一层；苦难值 93→68。
- 辅线推进：L05 账本当众救命（掌簿册对日子），报酬 7 万→32 万；L02 宁蘅人前装弱、关键时一句「我试试」，人前第一次露出一点硬（是她自己的选择）；打脸债「活不过冬」兑现（对称）。
- 事件线 / 任务线：围轩 → 太子到 → 孙嬷嬷跪告 → 搜妆奁 → 搜出私账 → 孙嬷嬷喊栽赃（卡出：账要落到人身上）→ 青梧对日子 → 「我试试」→ 押人 → 苦难值 68 → 太子盯上青梧 → 驿马。
- 感情线 / 关系线：试探阶段。人前宁蘅抓着她袖子发抖，人后两人心里都有底；宁蘅「我试试」是对孙嬷嬷，也是对自己。
- 逻辑线：孙嬷嬷告发 → 东宫来搜 → 搜出的是孙嬷嬷的账 → 青梧用支用账把账钉到孙嬷嬷身上 → 暗桩落网、公主洗清一层 → 新问题：太子盯上青梧；驿马带来新的压力。

#### 人物关系和出场顺序
- 出场顺序：秦戈（院门外）→ 东宫卫 → 元昭 → 孙嬷嬷 → 宁蘅 → 青梧（林迟）→ 描金妆奁、私账（关键物件）→ 掌簿册（关键物件）→ 宫门簿（被引用）→ 系统面板 → 驿马
- 人物关系变化：林迟×孙嬷嬷：同为陪嫁 → 她亲手把孙嬷嬷钉死；林迟×元昭：素不相识 → 他盯上了她；宁蘅×孙嬷嬷：被管着的「药罐子」→ 当面一句「我试试」；元昭×宁蘅：人质 → 他对公主的判断第一次松动（本章不写他的心思）。
- 视角/信息差：读者与林迟、宁蘅知道私账是调进去的，东宫与孙嬷嬷不知道；读者与林迟知道密信还在青梧手里；太子知道多少（他晾了两天在等什么），本章不交底。
