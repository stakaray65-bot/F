## 细纲（第 4 章）

### 第 4 章：跟屁虫自带行李箱
- 核心事件：林迟出院，不去陆家，回许知意自己的公寓，把温棠打发回学校；当晚温棠拖着行李箱按响门铃——「陆家知道我宿舍在哪」，林迟让她进了门；接下来几天温棠寸步不离地当跟屁虫，还递来一张写满「欠许小姐」的清单，林迟掐指节一算她还陆家三十万资助要还十二年半，转手把那张欠条撕了；苦难值卡在 72 不动，陆砚深发来「明天我过来」。
- 字数目标：2200 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01；单元第4拍「余波」（温棠搬进来、跟屁虫日常），为第5拍「新钩子」铺路
- 目标情绪：读者从第3章末「72 小时」那一刀里缓过来，跟着林迟「得拉开距离」的嘴硬和温棠一次比一次黏的跟法轻松笑出来；看财迷林迟把送上门的欠条撕掉，心里一暖；最后苦难值卡在 72、温棠的鞋挪到了卧室门口，把轻松落到一点微妙的心疼和好奇上——剩下这 72，原来有一部分在她自己身上。推进单元情绪引擎的「兑现之后」：温棠第一次被当成她自己对待之后，开始只围着这一个人转。
- 主角目标/关键选择：林迟要出院过两天清净日子，同时和温棠保持距离，免得走的时候难看。关键选择①：门铃响时，她要在「把人关在门外、守住距离」和「温棠回宿舍就在陆家眼皮底下」之间选——她让温棠进门，代价是距离从此拉不开；关键选择②：财迷本能对着一张送上门的欠条，她选择撕掉，不收温棠一分钱。
- 章首钩子：闪前碎片 — 先给一句后来的结果：林迟后来想，问题就出在她多嘴报了地址；再回到出院那天上午。
- 爽点：无显性打脸，低压生活章。小兑现：收获盘点（林迟当着面板数她的 28 万，顺手给温棠算账，「十二年半」的笑点）+ 情感圆满的小步（撕欠条，「我这儿不收账」）；往下看的理由是苦难值为什么不降、陆砚深明天要来。
- 本章禁止提前释放：
  - 违约金及其数额、资助协议里的条款都不出现；只放资助三年共约 30 万这一个数
  - 不出现律师函、流言、陆夫人（第5、6章）
  - 温棠本章不陪林迟去透析、不进血透中心（第8章透析日温棠陪着）；不画林迟的手（F08 第12章）
  - 本章不新增碎片残留，不写温棠挑香菜、学林迟的小动作；「1」不变化
  - 林迟不对温棠提 72 小时脱离；温棠不说「你会走吗」（第16章）

#### 内容概括（五段式）
- 起因：配型和合约拆了，林迟按答应陆砚深的条件定期回医院透析，人可以出院；陆砚深安排车要接她回陆家，她不去，从系统给的身份资料里翻出许知意自己的公寓。
- 发展：出院前温棠问她住哪，她随口报了地址，又把温棠打发回学校；林迟进了三年没人住的公寓，衣柜里一排白裙子——替身那身打扮原来是照这里抄的；当晚门铃响，温棠拖着行李箱站在门外，说陆家知道她宿舍在哪。
- 转折：林迟让她进门，从此甩不掉了：温棠跟着她进厨房、守在洗手间门口、她周三透析回来温棠已经在门口等着；温棠还递来一张清单，一笔一笔写着欠许小姐的粥钱、打车钱，最底下一行「陆家资助三年，约 30 万，另还」。
- 高潮：本章无高潮：功能是把「温棠只围着林迟转」立成日常，并用一张欠条把她「永远欠着别人」的心结摆到桌面上——林迟掐指节算出她靠画室代课还陆家要还十二年半，把清单撕了：「我这儿不收账。」
- 结尾：夜里林迟问系统合约都作废了苦难值为什么还是 72，系统只说处境一项里还剩死亡节点未过、资助协议仍在，其余属任务对象自身状态、不予解读；手机上陆砚深发来「明天我过来」；林迟起来倒水，看见温棠把沙发上的被子挪到了卧室门口打地铺，那双白色小皮鞋鞋尖对齐，摆在她门边。

#### 情节安排（多线）
- 主线推进：L01 在「第一个虐点拆除」之后转入「剩下的 72」：苦难值卡住，系统点出死亡节点未过、资助协议仍在、另有任务对象自身状态——为第5章律师函和后续「女主自己放下心结」铺底。
- 辅线推进：L02 从「温棠拒绝两清、主动留下」推到「温棠搬进来，跟屁虫日常」（不对劲第1格依赖粘人落地，试探阶段）；L05 从「报酬 28 万」推到「林迟顺手替温棠算资助账，十二年半」——卷纲「宿主掐指节算她的欠款」；L04 埋底：温棠换下白裙子穿回自己的旧卫衣，不再点那颗痣。
- 事件线 / 任务线：出院去向（卡出林迟主动远离陆家）→ 报地址 → 温棠找上门（卡出「宿舍在陆家眼皮底下」，逼林迟收人）→ 跟屁虫几天 → 欠条 → 苦难值卡住 → 陆砚深要上门。
- 感情线 / 关系线：试探阶段。温棠单方先黏，林迟给的回报是让她进门、撕欠条、不让她再穿白裙子——特殊待遇但林迟自己不认；拉开靠林迟心里那句「72 小时」，不说出口。不写肢体亲密，不写心动。
- 逻辑线：拆完虐点林迟出院、想拉开距离 → 温棠以宿舍不安全为由找上门，林迟收下 → 温棠黏着她、还拿出欠条，林迟撕了 → 苦难值卡在 72，系统点出死亡节点、资助协议和她自己的状态；新问题：陆砚深明天来，资助协议这根线还在陆家手里。

#### 人物关系和出场顺序
- 出场顺序：林迟 → 温棠（出院前的病房）→ 系统5468（许知意的身份资料）→ 陆砚深（电话，一句话）→ 许知意的公寓与一衣柜白裙子（关键场景）→ 温棠与行李箱、速写本 → 温棠的欠条（关键物件）→ 任务面板（72 / 28 万 / 倒计时）→ 陆砚深的短信 → 卧室门口的地铺与白色小皮鞋
- 人物关系变化：林迟×温棠：温棠主动留下、林迟想两清 → 两人同住，温棠寸步不离，林迟嘴上嫌弃、手上撕了她的欠条；林迟×陆砚深：表面和解 → 她拒绝回陆家，他每天来电她不怎么接，他宣布明天上门；温棠×白月光的影子：照许知意打扮 → 林迟一句「别穿白的了」，她换回自己的衣服、洗掉那颗痣。
- 视角/信息差：读者和林迟知道 72 小时脱离，温棠不知道；读者和林迟第一次听系统说苦难值里有「任务对象自身状态」，但都不知道具体是什么；温棠说「陆家知道我宿舍在哪」是不是全部理由，林迟没追问，读者自己掂量。
