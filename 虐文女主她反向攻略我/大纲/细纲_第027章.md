## 细纲（第 27 章）

### 第 27 章：罪奴没有份例档
- 核心事件：交易后的十八天风平浪静，苦难值稳在74。九月初二，南楚正使韦从简来漱玉轩请安，当着青梧把一颗蜡丸交到宁蘅手里：「皇后娘娘口谕，读完即焚。」宁蘅看完脸色发白，没烧，收进袖里，只说母后问她吃得好不好。当天午后苦难值跳到90：早朝裴相呈上界河「南楚细作」口供，说驻军数目是漱玉轩女官八月初五出承天门送去四方馆的，宫门簿上那天青梧确实出过宫；圣上口谕「秋狩誓师前查明，查实，以公主祭旗」。太子压不住，公主软禁漱玉轩，青梧押入掖庭。宁蘅这回没装晕，站得笔直：「姑姑，你吃饱。」掖庭晚饭一碗糙米半碟咸菜，林迟按份例档算了半天，罪奴没有档。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-05；单元第3拍「加压到底」
- 目标情绪：读者从第26章揭底的酸软里进来，先松一口——十八天没事；韦从简那颗蜡丸让心一沉，宁蘅在装、林迟看得出却没追问，读者跟着闷；苦难值跳到90、伪证拿青梧自己的行踪做底子，读者憋得发慌；宁蘅这回不装了，一句「你吃饱」是悲伤的峰值；掖庭吐槽伙食给一口透气，最后落回「7 天」。推进单元情绪引擎：本轮触发——伪证呈上、公主软禁、青梧下狱；缺口维持——母国的密旨是真的。
- 主角目标/关键选择：林迟要保住翻案的底子。关键选择：秦戈来拿人时，她可以当场辩——八月初五她去的是礼部、主事能作证；辩了也许能留下，但会被当场搜身，抄件就没了。她选择不辩、不求救，趁收拾的工夫把两页抄件塞进中衣夹层，跟着走。代价：背着细作同党的名进掖庭，掌簿册被收走。
- 章首钩子：反差场景 — 十八天里漱玉轩的账一页比一页平（宁蘅管账、亲卫换岗、面板上74一动不动），与九月初二早上韦从简那双磨亮的袖口并排落下。
- 爽点：无显性爽点，功能是加压到底、把单元压到最低点；笑点在掖庭伙食。往下看的理由：宁蘅袖里那颗蜡丸写了什么；7天里林迟在掖庭怎么翻。
- 本章禁止提前释放：
  - 密旨内容不揭（第29章宁蘅当众念出）；林迟与读者只知道是韦从简送来的、皇后口谕、读完即焚
  - 不揭三箱是军械、不揭裴相与韦从简合谋（第28章）
  - 太子不交底，只经秦戈一句「掖庭不比慎刑司」露一点护意
  - 宁蘅本章不装、不晕，也不说心结的话

#### 内容概括（五段式）
- 起因：第26章交易生效：东宫亲卫守轩，祭旗之议被太子以「和约未换、无据」压成「待查」，大婚推到十月。裴相那边要的是公主死，压住的只是一时。
- 发展：十八天里宁蘅管着轩里的账，青梧每两日把使团的动静报给秦戈，苦难值74不动（林迟嫌这十八天一文没赚）。九月初二上午韦从简来请安，要屏退左右；宁蘅说「姑姑留下」。韦从简递上一颗蜡丸：「皇后娘娘口谕，读完即焚。」宁蘅捏开看完，脸一点一点白下去，没烧，折好收进袖里；青梧问，她说「母后问我吃得好不好」。林迟看得出她在装，没逼。
- 转折：午后面板跳到90。秦戈带人进轩：早朝裴相呈上界河擒获的「南楚细作」口供——北燕驻军数目由漱玉轩女官八月初五出承天门、送到四方馆；宫门簿上八月初五青梧卯时出、午时回，属实；军报七名巡卒身中十四箭，箭是南楚制式。圣上口谕：秋狩誓师前查明，查实，以公主祭旗。
- 高潮：青梧想起八月初五她是去礼部抄入库单——伪证拿她自己的真行踪搭的架子，有人一直盯着她。她不辩，收拾时把两页抄件塞进中衣夹层；掌簿册被收走。宁蘅被亲卫拦在正殿门口，这回没晕也没哭，站得笔直，只说：「姑姑，你吃饱。」秦戈押人时低声一句：「殿下说，掖庭不比慎刑司。」
- 结尾：掖庭草铺上，林迟就着油灯看面板【当前苦难值：90】【死亡节点倒计时：7 天】，手按在中衣夹层那两页纸上。

#### 情节安排（多线）
- 主线推进：L01 压到最低点——伪证坐实「通敌」嫌疑，圣谕定了祭旗的时间；苦难值74→90，倒计时7天。
- 辅线推进：L02 宁蘅第一次在要紧时候不装——装可怜护不住了，她改成站直了送人（「你吃饱」）；L05 掖庭伙食按份例档算账的笑点；L04 十八天里宁蘅独自管账（一句带过，底子在长）。
- 事件线 / 任务线：十八天平静 → 韦从简送蜡丸 → 宁蘅藏旨撒谎 → 苦难值跳90 → 秦戈带来伪证与圣谕 → 青梧认出伪证的底子是自己的行踪 → 不辩、藏抄件 → 公主软禁、青梧押掖庭 → 掖庭伙食 → 7天。卡点：秦戈拿人这一卡，卡出「抄件保住、掌簿册丢了」，决定第28章她只能凭两页纸翻案。
- 感情线 / 关系线：试探阶段的一次「酸」。宁蘅对她瞒了一样东西，她也没逼——两边都在替对方扛；分开时只一句「你吃饱」。不写拥抱哭别。
- 逻辑线：太子压住祭旗 → 裴相与使团换更大的局（密旨送进来、伪证拿她行踪搭）→ 圣谕定期限、太子只能押人 → 青梧保抄件进掖庭 → 新问题：7天、一间草铺、两页纸，怎么翻；那颗蜡丸是什么。

#### 人物关系和出场顺序
- 出场顺序：漱玉轩十八天（概述）→ 宁蘅 → 青梧（林迟）→ 系统面板（74）→ 韦从简 → 蜡丸（关键物件）→ 系统面板（90）→ 秦戈、东宫亲卫 → 口供、宫门簿、军报（转述）→ 两页抄件、掌簿册（关键物件）→ 掖庭、掖庭令（路人）→ 糙米与咸菜 → 油灯、面板（7天）
- 人物关系变化：林迟×宁蘅：刚揭开底的一条心 → 第一次各瞒一点（她瞒蜡丸，林迟不逼）；林迟×元昭：交易生效 → 太子压不住、押她进掖庭，但选了掖庭不选慎刑司；林迟×韦从简：交割时见过一面 → 他当面递东西给公主，她记住了；宁蘅×母国：被换去和亲的弃子 → 母国送来一道口谕（内容未揭）。
- 视角/信息差：读者与林迟都不知道蜡丸写了什么；读者知道八月初五她是去礼部（第23章），伪证拿真行踪栽；读者经秦戈那句话能嗅出太子在护，林迟也听出来了。
