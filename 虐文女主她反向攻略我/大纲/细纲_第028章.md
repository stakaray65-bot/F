## 细纲（第 28 章）

### 第 28 章：五尺二寸的礼器
- 核心事件：掖庭的油灯底下，青梧把两页抄件摊开对：入库单末三箱「礼器，各长五尺二寸，重一百四十斤，使团封」，可南楚的青铜礼器在礼单第九十一到九十四号，箱长只有二尺四寸；倒是礼单第一百零三号「南楚猎弩两张，献北燕太子」，弩匣长五尺二寸，两张连匣三十五斤。一百四十斤正好八张弩一箱，三箱二十四张，一弩配箭二十五支，该六百支；界河七个巡卒身中十四箭——南楚的兵没过河，南楚的箭跟着「嫁妆」过了河。挂嫁妆名进城的是韦从简，拿死人提祭旗的是裴相。秦戈夜里隔着掖庭后门来问话，要先把她提出去，她不走，给了一个局：请太子奏准秋狩誓师当天按和约第九款当众点验一百三十一箱，逼那三箱在点验前没地方放；最顺手的去处是公主的帐——「别拦，让他们放。放完挪走。然后等他自己报数。」

- 目标情绪：读者从掖庭的最低处进来，看她拿指节当算盘一行一行对，憋着劲；「五尺二寸」两处对上那一下，震惊；十四箭对上、两人合谋浮出来，后背发凉又解气；秦戈说「先提你出去」她不走，读者急；局一摆出来，热血上来——这回轮到她下饵。推进单元情绪引擎：宿主不可替代的动作——在掖庭里把嫁妆清单和入库单一笔笔对，对出三箱军械，设秋狩局诱裴相自己去取。
- 主角目标/关键选择：林迟要在5天里拿出一条能当众翻案的证据链。关键选择：秦戈说殿下可以先把她提出掖庭；出去，人安全了，可对方立刻知道账在她手里，三箱会被毁掉。她选择留在掖庭，只把局交出去，并且不让太子直接搜裴府——要让裴相自己开口。代价：她自己再在掖庭关五天，局一旦失手，她跟公主一起上祭台。
- 章首钩子：未完成动作开局 — 她拿拇指掐着指节往下数，数到入库单倒数第三行，拇指停在食指根上不动了。
- 爽点：目标达成（证据链对出来）+ 信息反转（读者跟着她把裴相与韦从简一起揪出来）；往下看的理由：局摆好了，裴相会不会咬钩，在秋狩那天怎么开口。

#### 内容概括（五段式）
- 起因：第27章她背着同党之名进了掖庭，手里只剩两页抄件；死亡节点倒计时从7天往下走。
- 发展：九月初三白天浣衣，夜里就着油灯对账。入库单一箱一行，箱号、品名、尺寸、斤两、封签；末三行「礼器，各长五尺二寸，重一百四十斤，使团封」。礼单里南楚的祭祀礼器第九十一到九十四号，四箱各长二尺四寸——礼器在礼单里，使团自带的「礼器」说不通。再往下翻，礼单第一百零三号「南楚猎弩两张，献北燕太子秋狩，弩匣长五尺二寸，各配箭二十五支，连匣共重三十五斤」。
- 转折：五尺二寸对上了。一百四十斤，三十五斤两张，一箱八张，三箱二十四张、箭六百支。她想起秦戈转述的军报：七人身中十四箭。南楚的兵按和约第三款退了三十里，过河的是箭——跟着「嫁妆」进的城，挂名的是韦从简；拿七条人命提祭旗的是裴相。一个要打仗，一个要太子妃的位子，各取所需。
- 高潮：九月初四夜，秦戈按交易隔着掖庭后门来问话：「殿下问，要不要先把你提出去。」她说不走，把局交出去：请殿下奏准秋狩誓师当日由礼部会同使团，按第九款当众点验一百三十一箱；三箱在点验前必须没了，最顺手的去处是公主的帐，一箭双雕。「别拦，让他们放。放完挪走。然后等他自己报数。」秦戈问为什么不直接搜裴府，她说：「搜出来，他说是南楚栽给他的。得让他自己开口。」
- 结尾：秦戈要走，她叫住他：「韦大人给公主的东西，公主自己拿主意。」秦戈从怀里摸出一包帕子包着的炒栗子：「公主说，让姑姑吃饱。」她剥了一颗，面板角落【死亡节点倒计时：5 天】，她把栗子壳一颗一颗码在草铺边，码到第五颗：「初八，让他自己报数。」

#### 情节安排（多线）
- 主线推进：L01 秋狩翻案的证据链和局都在她手里成形；本卷信息反转（裴相与南楚使臣合谋、三箱是军械）由她对账揭出。
- 辅线推进：L05 从「账本是笑点」推到「账本救命」——两页抄件、指节当算盘；L02 隔着墙的一来一回：她让公主自己拿主意，公主送栗子让她吃饱。
- 事件线 / 任务线：浣衣 → 夜里对账 → 礼器尺寸对不上 → 猎弩匣同长 → 斤两算出二十四张、六百支 → 十四箭对上 → 合谋浮出 → 秦戈来问 → 不出掖庭 → 设局 → 托话、收栗子 → 5天。卡点：秦戈「先提你出去」——卡出她的选择：留下保住局。
- 感情线 / 关系线：试探阶段的隔墙互惦记；林迟托的话是「你自己拿主意」，不替她决定；宁蘅回的是「吃饱」。不写想念独白。
- 逻辑线：手里只剩两页纸 → 对出三箱是弩、箭对上界河 → 推出两人合谋 → 直接搜会被抵赖 → 设点验逼箱、放饵等报数 → 新问题：裴相会不会咬钩；誓师那天，那颗蜡丸会不会被拿来用。

#### 人物关系和出场顺序
- 出场顺序：青梧（林迟）→ 两页抄件（关键物件：入库单抄件、礼单末页抄件）→ 掖庭浣衣槽（场景）→ 油灯 → 礼单第九十一至九十四号、第一百零三号（关键条目）→ 系统面板 → 秦戈（掖庭后门）→ 帕子、炒栗子（物件）→ 面板（5天）
- 人物关系变化：林迟×秦戈：押人的卫率 → 替她传局的人（他第一次多问了一句「为什么」）；林迟×裴相、韦从简：被羞辱、被栽赃 → 她手里攥住了两人的账；林迟×宁蘅：隔墙互惦记，她第一次明说「你自己拿主意」。
- 视角/信息差：本章起读者与林迟同时知道三箱是军械、裴相与韦从简合谋；北燕朝堂与裴相都不知道她知道。宁蘅袖里的东西，林迟只猜到「韦送来的、多半是冲着公主去的」，不知道内容。
