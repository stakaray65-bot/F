## 细纲（第 7 章）

### 第 7 章：替身画的也配挂墙
- 核心事件：林迟陪温棠去松间画廊取画，老板宋启年当着客人对温棠说「替身画的东西也配挂墙？」，一转眼认出许知意本人立刻变脸；林迟翻出温棠的寄售合同，按第五条——画廊单方提前解约须提前三十日书面通知，否则按标价总额 30% 赔付——当场算出 5040 元，拒绝宋启年「许小姐把画买下，算我给您面子」的台阶，逼他把钱转给温棠、把画包好送上车；车开出去时，她看见宋启年在店里拿起电话，腰微微弯着。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-02；单元第2拍「尝试」（画廊退画羞辱，宿主砸场子）
- 目标情绪：读者先被宋启年当着客人那句话激得火起（温棠低着头一声不吭）；他认出许知意那一秒变脸，读者笑出来；林迟拿合同一条一条念、一笔一笔算，读者跟着解气；温棠收到 5040 时那句「我的画挣的第一笔钱」，解气落成一点酸软；结尾那通电话把读者拉回「这是有人在背后递话」的紧张。推进单元情绪引擎：本轮触发之一「画廊退画」，宿主用「算账」顶回去。
- 主角目标/关键选择：林迟要让温棠体面地把画拿回来，不白受这句话。关键选择：宋启年给了一个两边都好看的台阶——许小姐把三幅画买下，钱照付、面子照给；林迟选择不买，按合同让画廊赔，钱进温棠的账。代价：买下最省事、也最不得罪人；她选了让宋启年当着客人掏钱，结下一个记仇的人，也坐实「许小姐护着替身」的流言。
- 章首钩子：反差场景 — 画廊临街落地窗里挂着大幅油画，灯打得很亮；窗下的地上，温棠的三幅小画已经摘下来，裹着旧报纸靠墙立着。
- 爽点：打脸＋能力碾压（算账）——宋启年认出许知意后的变脸；林迟用合同条款把「退画」变成「赔钱」，当场标价 5040。往下看的理由：宋启年那通电话打给谁。
- 本章禁止提前释放：
  - 宋启年不服气、不改口（「替身画的东西也配挂墙」第14章由第三方转述兑现）；他不说出幕后是谁，只差点说漏「上面」
  - 林迟不动原主的钱（不买画），不提原主存款
  - 不出现温棠重新拿笔、不提画展（第12章）
  - 不碰病情、透析内容，只在章尾由司机提一句「明天透析」

#### 内容概括（五段式）
- 起因：第6章夜里画廊发来消息，让温棠上午去取走寄售了一年、一幅没卖的三幅画。
- 发展：两人到松间画廊，画已经摘下靠墙；宋启年当着两位客人对温棠说「替身画的东西也配挂墙？」，温棠低头去抱画。
- 转折：宋启年看清温棠身后的人，认出是许知意（陆家的未婚妻，照片上见过），立刻换上笑脸；林迟反问「她替的是我，那你说我配不配挂墙」，要过温棠夹在速写本里的寄售合同，念出第五条。
- 高潮：林迟掐指节算 4800+6000+6000＝16800，乘 30%，5040；宋启年请她把画买下「算我的面子」，她不买：「我买了是我掏钱，你赔了是你违约。」宋启年当着客人把 5040 转给温棠，嘴上还硬：「画嘛，还是没人买。」
- 结尾：店员把画包好抬上车；温棠低头看手机里的到账短信，说这是她的画挣的第一笔钱，林迟说「赔的也算挣」；车开出去时，林迟从后窗看见宋启年在店里拿起电话，腰微微弯着。司机说：「许小姐，明天透析，我八点来接。」温棠：「我陪你去。」

#### 情节安排（多线）
- 主线推进：L01 从「陆家拿债和流言压人」推到「陆家的手伸到温棠的画，被宿主当场顶回」——外部虐点拆一角，苦难值不动（处境大项未变）。
- 辅线推进：L05 从违约金账推到画廊赔付账（16800×30%＝5040）；L02 温棠被羞辱时第一次没躲到林迟身后，而是抱着画站着，等林迟算完；L04 底子——温棠的画被退回、换来第一笔「赔的钱」（主区间第12章起）。
- 事件线 / 任务线：取画 → 羞辱 → 认出许知意（卡出宋启年的势利：他怕的是陆家未婚妻）→ 合同条款 → 拒买画 → 赔付 → 那通电话。
- 感情线 / 关系线：试探阶段。林迟当着外人护她，温棠在车里抱着画、坐得很近；不写心动。
- 逻辑线：陆家递话让画廊退画 → 宋启年当众羞辱 → 林迟以合同反制、不出钱 → 画廊赔付、记恨 → 宋启年向上报信（新问题：陆家下一手）。

#### 人物关系和出场顺序
- 出场顺序：松间画廊（地点）→ 温棠的三幅画（关键物件）→ 宋启年 → 两位客人（路人）→ 林迟 → 寄售合同（关键物件）→ 店员（路人）→ 陆家司机（路人）
- 人物关系变化：宋启年×温棠：寄售方随手打发 → 当众被逼赔钱，记恨；宋启年×林迟：巴结许小姐 → 被许小姐当众下了面子；林迟×温棠：护在身后 → 温棠站在她旁边等她算完。
- 视角/信息差：读者从第6章的流言和陆夫人电话推得出画廊背后是谁，林迟也猜到，但本章不说破；宋启年认出「许小姐」只认这张脸和陆家婚约，不知道里面换了人。
