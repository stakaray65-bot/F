## 细纲（第 32 章）

### 第 32 章：对岸来了船
- 核心事件：九月廿六，宁蘅带着青梧和礼部主事到界河边的临渡驿筹办互市——青梧在这座驿站醒来过。对岸来了船：南楚皇后宫中掌事太监冯全奉国书渡河，宣懿旨：公主毁旨、擅退婚约，召回南楚问罪，一百二十八箱嫁妆随归。宁蘅自己拒了：「新和约第二款，互市主事由两国共认，非两国合议不得更易。母后要我回去，请先与北燕合议。」冯全转去要嫁妆，青梧撑腰：「礼单一百二十八箱，按旧约第九款入库，归公主。娘娘的箱子只有三箱，在北燕大理寺当证物，公公要，自己去领。」冯全临走留下皇后一封家书，宁蘅问他：「母后有没有问我一句好不好？」「娘娘只问公主听不听话。」苦难值28→24，就此不动；系统说处境项已清空。林迟想不通：外头的事都摆平了，还差什么。夜里隔壁宁蘅屋里的灯一直没灭。

- 目标情绪：读者从「一年顶两个太子妃」的轻快里来到界河边，秋水涨、对岸南楚旗，心里一紧；懿旨宣下来，憋；宁蘅拿新和约顶回去、青梧拿三箱怼回去，痛快；「娘娘只问公主听不听话」，痛快里扎进一根刺；24卡住、处境项清空，读者和林迟一起犯嘀咕——心结在哪。推进单元情绪引擎：缺口维持——母国的信、和亲的身份；最后一道外压由她自己顶回去，剩下的是心里那截。
- 主角目标/关键选择：林迟要把南楚这最后一道外压挡在河那边。关键选择：冯全拿「公主私通敌国」压人，她可以顺嘴把韦从简与密旨的事全抖出来，当场把南楚的脸撕干净；她选择只算嫁妆的账、只给宁蘅撑腰，不替她跟母国撕破——撕不撕是宁蘅自己的事。代价：冯全全身而退，还留下一封家书。
- 章首钩子：意象预示 — 界河秋水涨上来，漫过渡口第二级石阶，对岸南楚的旗被河风扯得直响。
- 爽点：打脸（冯全要嫁妆，被三箱军械顶回）+ 态度转变（宁蘅当着母国的人拒旨，不低头）。往下看的理由：外压清空却卡在24；那封家书写了什么；宁蘅屋里一夜不灭的灯。

#### 内容概括（五段式）
- 起因：第31章新和约写进互市，副使奏报皇后；互市定于十月初一在临渡开市，宁蘅带人来筹办。
- 发展：临渡驿还是那座两层木楼，青梧住回楼下偏间——她在这里醒来过，第一碗挑净香菜的粥也是在这儿喝的。宁蘅和礼部主事在楼上对着河滩丈量摊位，算一个摊位每月收几文地钱。对岸来了船，南楚旗，渡河的是皇后宫中掌事太监冯全，捧着国书：奉旨渡河。
- 转折：冯全宣懿旨：公主毁旨、擅退婚约、私通敌国，召回南楚问罪，一百二十八箱嫁妆随归；又添一句娘娘的话：「宁家没有不听话的女儿。你本就是替人嫁的。」宁蘅没跪，自己顶回去：新和约第二款，互市主事由两国共认，非两国合议不得更易；「母后要我回去，请先与北燕合议。」
- 高潮：冯全转去要嫁妆，青梧开口：礼单一百二十八箱，按旧约第九款点验入库，是公主的私产；「娘娘的箱子只有三箱，在北燕大理寺当证物，公公要，自己去领。」冯全脸色变了，收起懿旨，从袖里掏出一封皇后家书放在案上。宁蘅问：「母后，有没有问我一句好不好？」冯全：「娘娘只问公主听不听话。」船走了。
- 结尾：面板跳【当前苦难值：24】【当前报酬：760000 元】，之后一整天不动；系统：「处境项已清空。其余为任务对象自身状态，本系统不予解读。」夜里林迟躺在偏间看着24想不通，隔壁宁蘅屋里的灯一直亮着，她听见箱盖开了又合、开了又合。

#### 情节安排（多线）
- 主线推进：L01 最后一道外压（南楚召回、索要嫁妆）被挡回；处境项清空；苦难值28→24卡住。
- 辅线推进：L04 宁蘅以互市主事身份当着母国的人拒旨（自立的一步）；L02 林迟只撑腰不替她撕破母国；L05 嫁妆账当场顶回冯全。
- 事件线 / 任务线：到临渡 → 驿站旧地 → 丈量摊位 → 对岸来船 → 懿旨 → 宁蘅拒旨 → 冯全要嫁妆 → 青梧算账顶回 → 家书 → 「听不听话」→ 船走 → 24 → 处境项清空 → 夜灯与箱盖声。
- 感情线 / 关系线：试探阶段。撑腰是并肩，不是替她出头；冯全那句话之后林迟想说点什么，最后只把她那盏兔子灯点上挂到她门口。不写拥抱。
- 逻辑线：退婚抗旨 → 南楚来人召回 → 宁蘅凭新和约拒、林迟凭旧约第九款与三箱顶回嫁妆 → 外压清空 → 数字卡24 → 新问题：卡的是她心里——母国那句「你本就是替人嫁的」。

#### 人物关系和出场顺序
- 出场顺序：界河秋水、对岸南楚旗（意象）→ 临渡驿 → 青梧（林迟）→ 宁蘅 → 礼部主事（路人）→ 渡船 → 冯全 → 国书、懿旨（关键物件）→ 新和约（关键物件）→ 皇后家书（关键物件）→ 系统面板 → 兔子灯（物件）→ 隔壁的灯、箱盖声
- 人物关系变化：宁蘅×南楚皇后：被换去和亲的弃子 → 当着母国的人拒旨；母国回她一句「听不听话」；林迟×冯全：素不相识 → 当面拿三箱顶回去；林迟×宁蘅：同进同出 → 她第一次看着宁蘅关起门一个人扛。
- 视角/信息差：读者从第22章就知道宁蘅「替人嫁」，也知道苦难值含心结；林迟知道规则，却还没把24对到「替人嫁」上。家书内容林迟与读者都不知道。
