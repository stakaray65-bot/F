## 细纲（第 13 章）

### 第 13 章：名字要不要换一个
- 核心事件：征稿截止前一天，林迟陪温棠回美院盖推荐章，一路被认出「白月光本人来了」；导员好心劝温棠用个笔名避开流言，温棠自己在报名表上写下「温棠」，参展作是那只掐指节的手，题名《指节》；林迟在报名材料里读到简章第九条「对作品原创性存疑时，评审会可要求作者现场说明或现场创作」，记下了；校门口陆砚深在等，告诉她周敬已被安和停职调查，第一次叫了温棠的名字道歉，又对林迟说「等你好了，我们重新开始」；林迟问系统原主对这门婚事的意思，系统报出书桌左侧抽屉里有一封没寄出的信，她让陆砚深「过了下周再说」；四天后入围通知到，评委名单里有一个名字——严立鸿，和老宅茶室那幅字的落款一样。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-03；单元第1拍「建立期待」后半（她选择署自己的名字），并为第2拍「加压」埋入口
- 目标情绪：读者被导员那句「名字要不要换一个」捏紧——这是好意，也是流言的重量；温棠自己写下「温棠」两个字，读者心里一热；被一群学生围观「白月光本人」时林迟的尴尬与嘴碎，轻松一下；陆砚深第一次叫温棠的名字道歉，读者有一种迟来的舒坦；他提「重新开始」时读者跟着林迟一紧；最后「严立鸿」三个字出现，读者立刻想起茶室，紧张收在一个新的阴影上。推进单元情绪引擎：她不再只会当「像谁的人」，开始署自己的名字。
- 主角目标/关键选择：林迟要让温棠的报名顺顺当当走完，并且把陆砚深的婚事处理在原主的意愿上，不替原主拍板。关键选择：陆砚深当面提「重新开始」，林迟可以当场一口回绝、痛快了断；她选先问清原主的意思，压到下周、拿到原主自己的东西再谈。代价：婚约多悬一周，陆砚深带着希望走了；她要在死亡节点那几天同时扛两件事。
- 章首钩子：悬念对话开局 — 导员把报名表推回来，笔帽敲了敲署名那一栏：「温棠，名字……要不要换一个？」
- 爽点：态度转变（小）——陆砚深第一次叫温棠的名字、当面道歉；情感圆满的一小步——温棠自己选署名。笑点：林迟在美院被围观「白月光本人」。往下看的理由：评委名单上的严立鸿。
- 本章禁止提前释放：
  - 不出现评审现场、抄袭指控（第14章）；严立鸿只露名，不出场
  - 婚约不解除；致父母信只报位置，林迟本章不读信、不念内容（第15章）
  - 陆砚深不说「你不是她」（第15章）
  - 不说「你会走吗」；林迟不提 72 小时
  - 周敬的处置只到「停职调查」一句，不展开

#### 内容概括（五段式）
- 起因：第12章温棠拿起了笔；征稿截止在第32天，报名须美院院系盖推荐章。
- 发展：林迟陪温棠回美院，走廊上有学生认出那张脸，小声「白月光本人来了」，林迟冲他们挥手；导员办公室里，导员翻完作品照片，把报名表推回来，劝温棠用个笔名，「评委看了名字，先想到的是那些帖子」。
- 转折：温棠握着笔停了一下——像第5章签收单那样——在署名栏写下「温棠」，作品名《指节》；导员叹口气，盖了章。林迟翻报名材料，看到简章第九条，掐了一下指节，记住了。
- 高潮：校门口陆砚深在车边等着。他先对温棠说：「温棠，之前的事，对不起。」又对林迟说周敬已被安和停职调查，然后低声：「等你身体好了，我们重新开始，婚期的事——」林迟在心里问系统原主对婚事的意思，系统报：「所附身份资料：许知意书桌左侧抽屉内，有致父母未寄出信件一封。」她对陆砚深说：「过了下周再说。」
- 结尾：四天后，温棠手机响，入围通知，终评第39天在市美术馆当场公开评审；她把评委名单递给林迟，林迟一行行往下看，停在一个名字上——严立鸿，和老宅茶室那幅「淑仪雅正」的落款，一个字都不差。

#### 情节安排（多线）
- 主线推进：L01 从「剩下的处境是生计与名誉」推到「温棠以自己的名字入围、陆家最后一手的影子出现」；婚约问题被林迟压到下周。
- 辅线推进：L04 从「拿笔」推到「署自己的名字报名、入围」；L02 温棠在报名表上自己选，林迟站在旁边不替她说话——关系从「她护着她」推到「她看着她自己站」；L05 无（本章无账，不硬造）。
- 事件线 / 任务线：美院围观 → 导员劝笔名（卡出名声的重量）→ 署名 → 第九条（卡出林迟的布局抓手）→ 陆砚深道歉与「重新开始」→ 问系统原主意思 → 压到下周 → 入围与评委名单。
- 感情线 / 关系线：试探阶段。温棠落笔前看了林迟一眼，林迟没点头也没摇头；温棠写完，林迟说「字挺好看」。不写肢体。
- 逻辑线：要报名 → 导员好心劝笔名 → 温棠选真名 → 林迟记下第九条 → 陆砚深来求续约 → 林迟查原主意愿、压后 → 入围、评委里有陆夫人的旧识（新问题：终评现场会出什么事）。

#### 人物关系和出场顺序
- 出场顺序：导员（路人）→ 温棠 → 林迟 → 美院学生（路人）→ 报名表、简章第九条（关键物件）→ 陆砚深 → 周敬（只被提及）→ 系统5468 → 致父母信（只报位置）→ 入围通知、评委名单（关键物件）→ 严立鸿（只露名）
- 人物关系变化：陆砚深×温棠：只当替身、家宴后无话 → 第一次叫她名字、当面道歉；陆砚深×林迟：动摇 → 想重新开始，被压到下周；温棠×自己：怕流言 → 署自己的名字。
- 视角/信息差：读者和林迟都记得茶室落款，此刻同时对上；温棠不知道那幅字；陆砚深不知道原主出国是为躲他（第15章）；读者知道系统报了一封信，不知道信里写什么。
