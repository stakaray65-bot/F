## 细纲（第 19 章）

### 第 19 章：八十一万，暂不兑付
- 核心事件：林迟在一片白茫茫的系统空间里醒来，后颈还在疼、手还在抖；她追问那八十一万什么时候能花，系统只说「最终兑付以全部任务结算为准」，问全部是几个，不告知；问温棠，「任务世界已结束」；系统两次「建议宿主休整」，她两次拒绝，系统才说「已记录」。接入第二个世界：古代宫廷和亲，原书里南楚公主宁蘅被定为细作、秋狩前夜赐死，林迟附身的陪嫁女官青梧本该渡河落水后病死；她在临渡驿高烧醒来，床边守着一个圆脸大眼睛的少女——公主守了她三夜，把粥里的香菜一片片挑出去，说「你不吃这个」，问谁告诉的，答「没人」。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-04；单元第1拍「信息整理与入局」
- 目标情绪：读者从第18章的酸里出来，先被林迟追着系统讨薪逗笑，又从系统的含糊和「两遍休息」里嗅到不对；接入新世界，原书结局一报，压力重新拉起来；临渡驿那碗挑净香菜的粥，让读者心里一跳——跟温棠一模一样；「没人」两个字落地，读者比林迟先多想一步。推进单元情绪引擎：换地图、换低位身份，立起新的「被珍视」对象，和一个一见面就黏着她的公主。
- 主角目标/关键选择：林迟要搞清楚报酬到底能不能用，然后马上开工。关键选择：系统两次建议她休整，休整没有钱、却有一个说不清的「建议」；她可以听话歇着，也可以直接接入；她选择不休，接入第二个世界——嫌歇着不挣钱，也不想一个人在空白里待着想温棠。代价：后颈的疼和手抖带进了新身体（只一两句），她把它当工伤记下。
- 章首钩子：悬念对话开局 — 「5468，我那八十一万，现在能取多少？」
- 爽点：无显性爽点，功能是交代新规矩、立新世界；收获盘点式的小笑点：入账了却花不着；往下看的理由：系统在瞒什么；新公主为什么认得她不吃香菜。
- 本章禁止提前释放：
  - 报酬是幌子（卷3）；系统只含糊、不承认不否认
  - 后颈疼只按「正常穿越反应」说，不往代价上靠
  - 系统不说「不归本系统监测」（留给 F02 第34章）
  - 裴相与南楚使臣合谋、南楚皇后密旨、太子早知公主可能无辜都不出现
  - 宁蘅只露熟悉感，不说「梦」（第22章）；林迟只觉得「她怎么知道」，不得出「同一个人」的结论
  - 嫁妆、密信本章不出现

#### 内容概括（五段式）
- 起因：第17章脱离那一刻的剧痛之后，林迟被拉回系统空间；八十一万显示「已计入宿主账户」，她要知道这钱算什么。
- 发展：林迟追问报酬：能取多少、怎么换成现实的钱、什么时候能花；系统：「世界1报酬已计入宿主账户。最终兑付以全部任务结算为准。」「全部是几个？」「任务世界总数不予告知。」她又问后颈和手抖，系统：「该症状属正常穿越反应，会自行缓解。」问温棠，「任务世界已结束，本系统不再提供该世界信息。」系统接着：「温馨提示：建议宿主于系统空间休整后，再接入下一任务世界。」她问休整有钱吗，没有，不休；系统又建议一遍，她再拒，系统才说「宿主坚持接入，已记录」。
- 转折：接入。面板换了：【任务世界：第 2 个】【当前苦难值：100】【死亡节点倒计时：45 天】；原书结局一条条报出来——南楚公主宁蘅和亲北燕，太子冷遇，嫁妆里搜出密信、定为细作、秋狩前夜赐死；所附身份资料：青梧，南楚掌簿女官，管嫁妆册籍，原书里渡河落水，入燕第三日病殁。
- 高潮：林迟在临渡驿床上烧退醒来，床边坐着一个少女，圆脸，眼睛又大又黑，右耳垂一个小缺口；宫女在门口劝「公主，这不合规矩」——她守了三夜。孙嬷嬷进来催公主回房，「一个女官，哪劳公主守着」，放下一碗粥。宁蘅端起粥，拿勺子把浮着的香菜一片片挑出去，搁到她手边：「你不吃这个。」
- 结尾：林迟盯着那碗粥，嗓子发干：「谁告诉你的？」宁蘅想了想，自己也皱了眉：「没人。」林迟的手抬到一半，摸上了后颈。

#### 情节安排（多线）
- 主线推进：L01 世界2 入局——立原书结局、死亡节点倒计时 45 天、苦难值 100，青梧的掌簿身份给了宿主拆虐点的手段。
- 辅线推进：L03 系统破绽两处首露——报酬结算含糊（F10 埋）、催休息说两遍（F11 埋），后颈疼与手抖带进新世界（F09 余波）；F04 香菜第一次跨世界再现；L05 报酬入账却花不着；L02 从「你醒了」起步——宁蘅守了三夜，一见如故。
- 事件线 / 任务线：讨薪 → 含糊 → 问疼 → 问温棠 → 两次催休息 → 坚持接入 → 原书结局 → 驿馆醒来 → 公主守夜 → 孙嬷嬷 → 香菜 → 「没人」。
- 感情线 / 关系线：世界切换不清零，仍在试探阶段，起点比世界1 高：宁蘅守夜、挑香菜，不带敌意；林迟慢半拍，只当公主心善。
- 逻辑线：脱离 → 系统空间结算含糊 → 林迟坚持接入 → 附身濒死的青梧 → 宁蘅一见如故、挑香菜（新问题：她怎么知道；原书里公主四十五天后会死）。

#### 人物关系和出场顺序
- 出场顺序：林迟 → 系统5468 → 面板（八十一万）→ 系统空间（白茫茫）→ 面板（世界2 开局）→ 临渡驿偏间 → 宁蘅 → 门口宫女（路人）→ 孙嬷嬷 → 粥与香菜（关键物件）→ 铜盆水里的青梧（宿主新身体）
- 人物关系变化：林迟×系统：讨薪的打工人 → 第一次觉得它「说话绕」；林迟×宁蘅：陌生 → 公主守了她三夜，一碗挑净香菜的粥；林迟×孙嬷嬷：同为陪嫁 → 第一眼就被压一头；林迟×温棠：任务结束 → 系统不再给她那边的消息。
- 视角/信息差：读者知道香菜与「没人」是第2章温棠的原样，林迟也想起来了，但只到「她怎么知道」；读者已看过第17章的「活」字与剧痛，系统口中的「正常穿越反应」读者半信半疑；宁蘅自己也不知道为什么。
