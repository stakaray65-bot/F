## 细纲（第 15 章）

### 第 15 章：今天是手术日
- 核心事件：死亡节点倒计时只剩最后一天——原书里温棠死在手术台的日子，林迟一早就疑神疑鬼，关煤气、拔插头、不许温棠出门，温棠被她逗笑；她从书桌左侧抽屉里取出许知意没寄出的信，信里写着出国不只是治病，她不想嫁给陆砚深；陆砚深带着戒指盒来谈婚期，林迟把信给他看，当面解除婚约，许母在电话里说「听你的」；陆砚深看了她很久，说「你不是她。她从来不跟我说不」，放下戒指盒走了；夜里两人守着钟，零点面板跳出「死亡节点已度过」，苦难值 33→23；林迟掐着指节数——再降四点，她就得走，拇指停在第四个指节上。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-03；单元第3拍「兑现」后半（死亡节点日平安度过、宿主当面解除婚约）
- 目标情绪：读者从第14章的痛快带着一点悬心进来——「手术日」；林迟草木皆兵、温棠被她逗笑，轻松又甜；信里那句「我不想嫁」让人替原主松一口气；陆砚深那句「你不是她」让读者心里一跳（他看出来了？），又落回一个原男主体面的放手，一点怅然；零点「死亡节点已度过」，长出一口气；最后林迟拇指停在第四个指节——读者突然明白剩下的四点意味着什么，暖里压进一层沉。推进单元情绪引擎：外部虐点全部拆完，只剩她自己的心结；兑现之后，代价开始露头。
- 主角目标/关键选择：林迟要让温棠平平安安过完原书的手术日，并把许知意的婚事按许知意自己的意思了断。关键选择：陆砚深带着戒指来，真心想重来，许家父母不再替陆家说话，留着这门婚约对林迟这个「过路人」毫无代价、甚至能多一层陆家的照应；她选按原主的信当面解除，替原主说了那个原主没敢说的「不」。代价：她亲手断了陆砚深最后的念想，也被他一句「你不是她」看得心里一紧；零点之后她才发现，任务离完成只剩四点。
- 章首钩子：倒计时开局 — 面板一睁眼就在：【死亡节点倒计时：1 天】；林迟在心里说：今天是原书里的手术日。
- 爽点：目标达成＋情感圆满（原主与陆砚深两清）——解除婚约，零点死亡节点平安度过；收获盘点：苦难值 33→23，报酬 67万→77万。往下看的理由：再降四点就得走，而温棠还不知道。
- 本章禁止提前释放：
  - 不说「你会走吗」（第16章）；林迟不告诉温棠 72 小时，温棠不问
  - 苦难值停在 23，不跌破 20；72 小时倒计时不出现
  - 林迟不承认、不否认自己不是许知意；「你不是她」只落在「你变了／她不会说不」的层面，不触发违规疼痛
  - 不出现碎片收回、后颈剧痛、异常数值变化（第17章）；系统不催休息（第19章）
  - 信只念与婚事相关的两三句，不扩写原主的其他心事

#### 内容概括（五段式）
- 起因：第14章陆砚深约了「后天谈婚期」，正落在死亡节点倒计时的最后一天；第13章系统报了原主那封信的位置。
- 发展：林迟一早起来就草木皆兵：关煤气阀、拔电热水壶插头、把阳台门锁上、不许温棠出门买菜，温棠站在厨房门口看着她，笑出了声，煮了两碗面。上午林迟拉开书桌左侧抽屉，取出一只没贴邮票的信封，收信人「爸、妈」，里面一页信纸，写着出国不只是治病，「我不想嫁给陆砚深，可我不敢跟你们说」。
- 转折：下午陆砚深来了，西装熨得很平，手里一只深蓝丝绒戒指盒；他说婚期可以往后推，等她身体好。林迟把信推过去；他读完很久没说话。林迟给许母打电话，许母听完只说了一句「听你的」。林迟：「这婚约，解了吧。」
- 高潮：陆砚深看着她，看了很久：「你不是她。她从来不跟我说不。」林迟没认也没否：「她一直想说，只是没说出口。」陆砚深把戒指盒放在茶几上，起身前对温棠点了点头，走了。
- 结尾：夜里两人坐在沙发上守着墙上的钟，温棠不知道她在等什么，也陪着不睡；零点一过，面板跳出：【死亡节点已度过】，接着两行，苦难值 23，报酬 770000 元；温棠靠着沙发扶手睡着了，白色小皮鞋鞋尖对着林迟摆着。林迟右手拇指一节一节掐下去——二十三到十九，四点——掐到第四个指节，停住了。

#### 情节安排（多线）
- 主线推进：L01 从「生计与名誉翻过来、只剩死亡节点」推到「死亡节点平安度过、婚约解除，处境项清空，苦难值 23」——世界1 外部虐点全部拆完；卷纲期待「死亡节点平安度过」兑现。
- 辅线推进：L02 从「她站上去时她在旁边」推到「她陪着守一个不知道为什么要守的零点」，林迟第一次数清了离别的距离（为第16章「你会走吗」蓄力）；L05 报酬 67万→77万，账第一次算成了「离走还有几点」。
- 事件线 / 任务线：手术日疑神疑鬼 → 取信（卡出原主意愿）→ 陆砚深来谈婚期 → 信 → 许母「听你的」→ 解除婚约 → 「你不是她」→ 守零点 → 死亡节点已度过 → 四个指节。
- 感情线 / 关系线：试探阶段。温棠被她逗笑、陪她守钟、靠着扶手睡着；林迟数到第四个指节——推拉的「拉开」靠必须离开这个心结；不写肢体亲密、不写心动独白。
- 逻辑线：死亡节点日 → 林迟守着温棠 → 陆砚深来求婚期 → 林迟以原主的信、许母的同意解除婚约 → 陆砚深看出「她变了」、放手 → 零点死亡节点过 → 苦难值 23（新问题：剩下的只在温棠心里，再降四点林迟就得走）。

#### 人物关系和出场顺序
- 出场顺序：系统面板（倒计时）→ 林迟 → 温棠 → 煤气阀、插头（道具）→ 原主致父母信（关键物件）→ 陆砚深 → 戒指盒（关键物件）→ 许母姚佩（电话）→ 墙上的钟（意象）→ 系统面板 → 白色小皮鞋（意象）
- 人物关系变化：林迟（许知意身份）×陆砚深：婚约悬着 → 解除；陆砚深×「许知意」：想重来 → 认出「你不是她」，放手；陆砚深×温棠：道歉过 → 临走点头；林迟×温棠：她在旁边 → 她陪着守零点、在她身边睡着；林迟×自己：救完就走 → 数清了还剩四点。
- 视角/信息差：读者知道「你不是她」字面上说中了，陆砚深不知道——他只是觉得她变了；读者与林迟知道零点意味着什么，温棠只当她在等一个莫名的时间；读者知道再降四点＝72 小时倒计时开始，温棠不知道。
