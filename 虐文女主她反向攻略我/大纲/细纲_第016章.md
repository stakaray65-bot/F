## 细纲（第 16 章）

### 第 16 章：冰箱上贴满了便利贴
- 核心事件：死亡节点过后第一天，林迟开始替温棠安排「以后」——算美院后街单间的押一付三、把透析改回每周一次、在冰箱上贴满电话便利贴；温棠自己回绝了松间画廊的签约，却从那排便利贴里看出了什么，夜里在卧室门口问「你会走吗」；林迟没有骗她：「会。但你不用像谁，也能被留下。」温棠从速写本里抽出作废合约和资助协议原件，自己撕了；苦难值 23→19，任务完成，72 小时倒计时跳了出来。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-03；单元第4拍「心结」（「你会走吗」，苦难值跌破 20）
- 目标情绪：读者从第15章末那四个指节的沉里进来，先被林迟一本正经算房租、贴便利贴逗笑，又笑着发觉她在交代后事；温棠回绝宋启年那一下小痛快；夜里「你会走吗」一出，心一下提起来——怕她撒谎，又怕她说实话；「会」落地时一刀，后半句「你不用像谁，也能被留下」把温棠三年的心结正面接住；温棠自己撕掉那两张纸，读者跟着松开，却在倒计时出现的瞬间重新揪住。推进单元情绪引擎：宿主不可替代的动作——在「你会走吗」面前说真话；兑现：苦难值 19，代价是 72 小时。
- 主角目标/关键选择：林迟要在走之前把温棠的路铺好，把最后四点降下去。关键选择：温棠问「你会走吗」时，撒谎说「不会」最省事，能让她今晚睡个好觉，也不碰苦难值；说真话可能让她当场崩、让数字往回涨。林迟选择说真话，并把她最怕的那件事——「只有像谁、有用才配被留下」——一起正面说破。代价：她亲口把离开说出来，再也瞒不住；温棠撕纸之后，倒计时立刻开始。
- 章首钩子：未完成动作开局 — 温棠在沙发上醒来，林迟盘腿坐在茶几前，拇指正掐到第三个指节，嘴里念着「押一、付三」，见她醒了才停。
- 爽点：情感圆满（温棠心结正面被接住，自己撕掉替身时代最后两张纸）＋目标达成（苦难值 23→19，任务完成，报酬 81 万）；小打脸：温棠自己回宋启年「不签」。往下看的理由：72 小时倒计时开始，温棠知道她会走，却不知道多快。
- 本章禁止提前释放：
  - 林迟不说为什么走、去哪、什么时候；不提系统与穿越（只说「会」）
  - 不出现碎片收回、后颈剧痛、异常数值变化（第17章）
  - 温棠不哭闹、不挽留成「别走」，不越过依赖粘人（不对劲第1格封顶）
  - 不写肢体亲密与心动独白；感情线停在试探
  - 宋启年不出场

#### 内容概括（五段式）
- 起因：零点死亡节点已过，处境项清空，苦难值卡在 23——剩下四点全在温棠心里；林迟数清了离走只差四点，开始替她安排走后的日子。
- 发展：林迟一早翻租房软件，算美院后街单间：月租一千二、押一付三四千八，金奖五万付完还剩四万五千二，每月房租加吃饭两千七，撑十六个月；温棠问「我住这儿不行吗」，林迟说「你得有个自己的门牌号」。同学又转来宋启年的签约邀请，温棠这回自己回了两个字：「不签。」下午林迟打电话给安和血透中心，把透析改回每周一次，又在冰箱门上贴了一排便利贴：周三透析、物业、血透中心、「妈」的号码。
- 转折：温棠站在冰箱前看那排便利贴看了很久——每张都是给「以后」的，没有一张写着林迟自己会在哪。
- 高潮：夜里温棠坐在卧室门口的地铺上，隔着门问：「你会走吗？」林迟在心里问了 5468 一句，系统答「仅陈述离开，不构成违规」。她开门坐到地铺边：「会。」停了很久，「但你不用像谁，也能被留下。」温棠没哭，翻开速写本，抽出夹了一个多月的作废合约和资助协议原件，自己一下一下撕了。
- 结尾：面板跳出【当前苦难值：19】【任务完成】【当前报酬：810000 元】，系统：「温馨提示：宿主将于 72 小时后脱离本世界。」倒计时【71:59:59】开始走；温棠把地铺从门口拖到了床边，攥着林迟一角袖子睡着了，林迟睁着眼看那串数字一秒一秒往下掉。

#### 情节安排（多线）
- 主线推进：L01 世界1 任务完成——苦难值 23→19，女主已活过原书死亡节点；「救了她就得走」第一次兑付开始（72 小时）。
- 辅线推进：L02 从「她陪着守零点」推到「你会走吗」与「会」——第一次告别开始，F17 母题立起、F18（72 小时瞒着她）与 F19（苦难值卡在心结）回收；L04 温棠自己回绝画廊签约、租下自己的房间，从「署自己的名」推到「有自己的门牌号」；L05 掐指节算押一付三，报酬 77 万→81 万。
- 事件线 / 任务线：算房租 → 回绝画廊 → 改透析 → 贴便利贴 → 温棠看出来 → 「你会走吗」→ 说真话 → 撕纸 → 任务完成 → 72 小时。
- 感情线 / 关系线：试探阶段。推拉里的「拉开」落在「必须离开」这个心结上；温棠把地铺拖到床边、攥着袖子睡，是依赖粘人的顶点，不越格。
- 逻辑线：苦难值卡在心结 → 林迟铺后路 → 便利贴暴露她要走 → 温棠问 → 林迟说真话并点破「不用像谁」→ 温棠自己撕掉替身时代的两张纸 → 苦难值 19、任务完成 → 新问题：72 小时后她必须走，温棠只知道「会」。

#### 人物关系和出场顺序
- 出场顺序：温棠（沙发上醒来）→ 林迟（掐指节）→ 租房软件 → 同学转来的宋启年消息（转述）→ 安和血透中心（电话）→ 冰箱便利贴（关键物件）→ 地铺与卧室门 → 系统5468 → 速写本、作废合约、资助协议原件（关键物件）→ 系统面板 → 脱离倒计时
- 人物关系变化：林迟×温棠：她陪着、林迟瞒着 → 林迟亲口说「会走」，温棠知道了；温棠×自己：只会当像谁的人 → 自己撕掉替身合约与资助协议，租自己的房；温棠×宋启年：被求签 → 她自己回绝。
- 视角/信息差：读者与林迟知道 72 小时、知道最后四点在心结上；温棠只知道「会走」，不知道多快、为什么；林迟以为温棠是看便利贴猜到的，读者看得出温棠其实早在留意她（第12章她就盯着那只算账的手）。
