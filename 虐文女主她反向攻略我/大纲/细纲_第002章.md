## 细纲（第 2 章）

### 第 2 章：连体检都包了
- 核心事件：第二天一早周敬带着初配报告来催术前检查——温棠的血是上个月资助体检时抽的、她本人不知情；林迟当着陆砚深和周敬拒绝移植、改回规律透析，下午拖着身子透了四小时，温棠趁乱藏下一页配型报告，晚饭时又不声不响替她挑掉了碗里的香菜。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01；单元第2拍「加压」（配型提前、宿主拒收器官硬顶、温棠藏下配型报告），同时立「女主为什么认识我」期待债（F04 香菜）
- 目标情绪：读者从第1章撕合约的余热，被「她的血早就被抽去配型了」一下按进发冷和愤怒；跟着林迟当众一句「不换」出一口气，又被「配型安排未取消、苦难值还是 100」压回紧张；透析后的虚脱给出代价感，最后落在温棠挑香菜带来的发毛的好奇上——她背过许知意爱吃香菜，手却替林迟挑干净了。推进单元情绪引擎的「缺口维持→宿主不可替代的动作」：陆家的配型数据捏在周敬手里，林迟用受者本人的身份亲口拒收。
- 主角目标/关键选择：林迟要把今天的术前检查挡掉，不让温棠被带走。关键选择：在不知道这具身体到底病到什么程度（系统不做医学判断）的前提下，当众拒绝活体移植、改回规律透析——拿原主的身体去赌，代价是当天下午就躺上透析床、在陆砚深眼里坐实「病糊涂了」；同时她看见温棠藏了东西，选择不问、不收，让温棠自己留着。
- 章首钩子：意象预示 — 天刚亮，林迟睁眼先看视野角落，那个「1」还亮着、一动不动；陪护床上被子叠成豆腐块，像有人随时准备走。
- 爽点：当众拒收（打脸前奏 + 目标达成·部分）——陆家连夜提前的术前检查被受者本人一句话卡住，周敬只能把检查改到明天；小爽点：林迟掐指节算透析账的财迷笑点；温棠第一次正眼看她（关系上的小松动）。
- 本章禁止提前释放：
  - 不揭示、不暗示周敬夸大病情；不给许知意的分期、肌酐等任何指标数字（第8章起）
  - 配型安排与备份合约本章都不取消、不作废，苦难值全章保持 100（第3章 100→72）
  - 不读配型报告的具体内容，温棠不说藏它做什么（F06 第9章交出）
  - 温棠不解释香菜、系统不评论香菜；异常数值「1」本章不变化
  - 陆夫人只以「夫人那边」被提一句，不出场、不露她的算盘；不出现「不要任何人替我活」类台词（第3、5章）

#### 内容概括（五段式）
- 起因：昨夜合约被撕，但签约安排和配型都还在；陆家连夜把术前检查提到今天，周敬一早带着初配报告上门。
- 发展：周敬当着三个人说出「温小姐与许小姐初配相合」，用的是温棠上个月资助体检时抽的血——温棠第一次知道合约里那条医疗配合条款通向哪里；林迟问系统不换肾会怎样，系统只答「医学判断不在本系统服务范围内」。
- 转折：林迟当众拒绝移植、改回规律透析，过激到自己都意外，一把挥落文件夹；陆砚深认定她病糊涂了，周敬顺势只把检查改到明天，排期不动；系统确认「受体拒绝已记录，配型安排未取消」——今天守住了，事情没完。
- 高潮：下午血透中心四小时，林迟冷、抽筋、反胃，被推出来时看见等在外头的温棠速写本里夹着一页带安和医院抬头的纸；温棠合上本子，第一次正眼看她，问「你真的不要？」，她答「不要」，没伸手去拿那页纸。
- 结尾：晚饭的粥上撒满了香菜（陆先生交代过许小姐爱吃），林迟还没皱眉，温棠已经一片一片替她挑干净，把碗推回来说「你不吃这个」；林迟问谁告诉她的，温棠看着自己捏筷子的手，说「没人」。

#### 情节安排（多线）
- 主线推进：L01 从「签字被截、签约安排未取消」推到「受者当众拒收、今日术前检查被挡，但配型排期与备份合约仍在」——第一个虐点被顶住第二次，仍未拆掉。
- 辅线推进：L02 从「温棠带刺设防」推到「温棠第一次正眼看她、问她真的不要」，仍在相识阶段；L03 碎片残留首露（F04 温棠挑香菜，且与她背过的许知意喜好相反），F01「1」只确认还在；L04 埋一笔温棠随身带速写本（第12章起的画笔线底子）；L05 林迟掐指节算四十天透析次数，报酬仍是 0 元。
- 事件线 / 任务线：陆家提前术前检查 → 周敬拿出初配报告（卡出「温棠的血早被用了」，温棠的处境与动机在此落地）→ 林迟拒收 → 周敬改到明天、排期不动（卡出「只挡住一天」，接第3章）→ 下午透析（代价落地）→ 晚饭香菜。
- 感情线 / 关系线：相识阶段，互相设防仍在。温棠从「白月光演给陆先生看」动摇到「她好像是真的不要」；林迟没有任何好感动作，只是没拿走温棠藏的东西。不写肢体亲密、不写心动。
- 逻辑线：陆家要按原计划配型 → 周敬用资助体检的血做了初配、把检查提到今天 → 林迟以受者身份拒收、改透析 → 今天的检查被挡、排期没取消，林迟身体付了一次透析的账 → 温棠知道了自己是供体、藏下一页报告；新问题：明天的检查怎么办，温棠为什么知道她不吃香菜。

- 出场顺序：林迟 → 异常数值「1」与任务面板 → 温棠（洗手池前，镜子里两张脸）→ 陆砚深 → 周敬 → 初配报告（关键物件）→ 系统5468 → 血透中心护士（路人）→ 温棠的速写本与夹着的那页纸（关键物件）→ VIP 病房送餐护工（路人）→ 撒满香菜的粥
