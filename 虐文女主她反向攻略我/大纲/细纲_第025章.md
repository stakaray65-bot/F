## 细纲（第 25 章）

### 第 25 章：打雷那夜，东宫来人
- 核心事件：孙嬷嬷走后，宁蘅要青梧教她看账、打算盘，一个下午就把漱玉轩半个月的支用对平了；入秋第一场雷雨夜，她抱着枕头钻进东耳房，说怕雷，挤上了青梧的床。秦戈冒雨来传青梧去东宫问话，宁蘅一声雷就抖得攥紧她，青梧只好回「公主惊着了，明日再去」。黑暗里宁蘅学着她的样子，拿拇指一节一节掐着指节数雷，问「你会不要我吗」。次日一早，青梧在承天门外礼部廊下等着交账，面板突然从 68 跳到 78——散朝的官员说，界河北岸七个巡卒被杀，裴相在殿上提了「斩和亲公主祭旗」。青梧开口问了一句：和约第三款南楚退兵三十里，界河边哪来的南楚兵？裴相笑眯眯地停下：「一个女官，也配在朝堂外议国事。」
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-05；单元第1拍「余波与新压力」
- 目标情绪：读者从第24章的痛快里落进一段低压：宁蘅学算账学得飞快，读者跟着青梧又惊又乐；雷雨夜挤床，甜，林迟嘴碎又没辙；秦戈叩门、宁蘅一抖把人留下，读者先当她粘人；她拿拇指掐指节数雷，读者心里「咯噔」——那是温棠画过的手；「你会不要我吗」软得发疼。次日数字一跳、「祭旗」两个字砸下来，甜一下收紧；青梧问出那一句，裴相一句讥讽把憋屈推到顶，读者攒着劲等她还。推进单元情绪引擎：缺口维持（母国要她当刀、敌国要她当祭品）＋本轮触发前奏（边境摩擦、祭旗）。
- 主角目标/关键选择：林迟要护着宁蘅过这一劫，先弄清楚边境那桩事是真是假。关键选择：在承天门外，她只是个来交账的女官，闭嘴最稳；开口问，等于当着满朝官员给自己挂个靶子。她选择开口，用和约第三款问出那个谁都没问的疑点。代价：裴相当众羞辱她，记住了她；她让自己也进了这盘棋。
- 章首钩子：意象预示 — 燕都入秋，午后天边压着一层铅色的云，院里那株海棠的青果子被风吹得一串串乱晃。
- 爽点：态度转变（小）——宁蘅一个下午学会看账、把半个月支用对平，青梧服气；无显性打脸（裴相的讥讽是立债，第29章还）。往下看的理由：太子半夜要问她什么；有人要拿公主祭旗；青梧那一问会招来什么。

  - 掐指节只写宁蘅学她数雷，林迟只「咯噔」一下，不得出「同一个人」的结论
  - 不揭界河冲突是谁做的局，不揭裴相与韦从简合谋、三箱军械（第28章）
  - 不出现南楚皇后密旨（第27章）
  - 苦难值不降到 20 以下、宁蘅心结不放下（第33章）；不提退婚（第31章）
  - 密信本章不拿出来（第26章交易）

#### 内容概括（五段式）
- 起因：第24章孙嬷嬷落网、那夜驿马送来界河第一回摩擦（两边巡卒隔河对射，没死人）；漱玉轩的起居账没人管了，宁蘅说她来管。
- 发展：午后宁蘅搬了小算盘坐到青梧对面，要她教看账；青梧教了一遍，她就把漱玉轩半个月的支用对平了，连孙嬷嬷多报的两笔炭钱都挑了出来，青梧看得直咂嘴。夜里入秋第一场雷雨，宁蘅抱着枕头钻进东耳房：「我怕雷。」挤上了青梧的床。
- 转折：雨里有人叩门，是秦戈：「殿下传青梧姑姑去东宫问话。」一声炸雷，宁蘅抖得攥紧青梧的袖子，眼泪都出来了；青梧回：「公主惊着了，明日再去。」秦戈看了宁蘅一眼，走了。黑暗里，宁蘅拿右手拇指一节一节掐着自己的指节，一道雷掐一下。青梧看见了，心里一咯噔。宁蘅小声问：「你会不要我吗？」她答：「我在这儿一天，就管你一天。」
- 高潮：次日一早，青梧去承天门外礼部廊下交漱玉轩的账，等着等着，面板一跳：【当前苦难值：78】。散朝的官员三三两两出来议论：八月十一夜，界河北岸北燕巡卒七人被杀，现场留着南楚的箭；裴相在殿上提了「斩和亲公主祭旗，以正国威」。青梧开口：「和约第三款，两国各退兵三十里。界河边上，哪来的南楚兵？」廊下一静。
- 结尾：一个圆脸白面、须修得一丝不乱的紫袍老者停下脚，笑眯眯地看她：「一个女官，也配在朝堂外议国事。」身后官员一阵笑。远处承天门下，元昭驻着马，看着这边。面板角落：【死亡节点倒计时：26 天】。青梧按了按袖里掌簿册的封皮——那封信还在里头。

#### 情节安排（多线）
- 主线推进：L01 世界2 新一轮压力立起——边境摩擦、裴相提「祭旗」，苦难值 68→78；死亡节点倒计时 26 天。
- 辅线推进：L02 从配合演戏推到装怕雷挤床、挡下东宫来人，「你会不要我吗」（不对劲第2格内加码；「怕雷偏挑太子派人来的那夜」动机反转铺垫）；L04 宁蘅学算账、对平半个月支用（为第31-34章主持互市埋）；L03 跨世界小动作再现——宁蘅学她掐指节数雷（F08 呼应）；打脸债「一个女官，也配在朝堂外议国事」立起（第29章兑现）。
- 事件线 / 任务线：学账 → 雷雨挤床 → 秦戈传人（被挡回）→ 掐指节数雷 → 「你会不要我吗」→ 承天门外交账 → 苦难值 78 → 「祭旗」→ 青梧质疑 → 裴相讥讽 → 太子远看。
- 感情线 / 关系线：试探阶段。宁蘅挤床、学她的动作、问「你会不要我吗」，是装可怜小心机的加码；林迟答得实在、不许诺，嘴碎地嫌她占床。不写心动独白，不越过同榻而眠的分寸（只挤着睡，不写亲密）。
- 逻辑线：孙嬷嬷倒了 → 宁蘅接手起居账（L04）→ 雷雨夜东宫来传人，宁蘅挡回 → 次日边境死人、裴相提祭旗 → 青梧当众质疑 → 被裴相羞辱、被太子看见 → 新问题：太子要问她什么；祭旗这一刀怎么挡。

#### 人物关系和出场顺序
- 出场顺序：铅云与海棠青果（意象）→ 宁蘅 → 青梧（林迟）→ 小算盘、漱玉轩支用账（关键物件）→ 雷雨 → 东耳房 → 秦戈 → 宁蘅掐指节（关键动作）→ 承天门、礼部廊下 → 系统面板 → 散朝官员（路人）→ 裴延（裴相）→ 元昭（远处）→ 掌簿册封皮里的密信（关键物件）
- 人物关系变化：林迟×宁蘅：一条船上 → 宁蘅学她算账、学她掐指节，问「你会不要我吗」；林迟×裴相：素不相识 → 当众被他羞辱；林迟×元昭：被盯上 → 他第二次看着她，这回是在朝堂边上；宁蘅×元昭：人质 → 她挡下了太子派来的人（本章读者只当巧合）。
- 视角/信息差：读者看见宁蘅偏偏在东宫来人那一刻怕雷，林迟只当她怕雷；读者知道掐指节是林迟的习惯、温棠画过那只手，林迟只「咯噔」；读者与林迟都不知道边境死人是谁的局；太子在想什么，本章不交底。
