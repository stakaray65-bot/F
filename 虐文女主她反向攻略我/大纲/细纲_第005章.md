## 细纲（第 5 章）

### 第 5 章：为个替身，值吗
- 核心事件：陆砚深一早上门，开门的是穿旧卫衣、洗掉了痣的温棠，他一时没认出来；他带着周敬「透析撑不了太久」的话来劝，提出让许知意搬回陆家老宅、温棠回学校、他保证不碰她，林迟不答应；他问「为个替身，值吗」，林迟答「她叫温棠」，算完那三十万资助买的是什么，说出「我不要任何人替我活」；陆砚深留下一句「我妈那边不会就这么算了」走了，下午律所的人送来一封写给温棠的律师函，温棠握着笔在签收栏上签了自己的名字。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01；单元第5拍「新钩子」（陆砚深上门质问、陆夫人律师函），并作为下一单元 L1-02 的因果入口
- 目标情绪：读者从第4章的轻松被门铃拎回紧张；看陆砚深不认得温棠的那一下，先出一口「替身那层皮掉了」的气；跟着他真心的着急和让步方案被压得有点难受——他不是坏人，可他的方案仍旧把温棠当件东西；林迟一句「我不要任何人替我活」把压着的那口气顶出来，温棠在厨房门口听见；最后律师函送到、温棠在签收栏写下自己的名字，紧张收在一个新的威胁上。推进单元情绪引擎的「兑现之后的反扑」：陆家明面上的人退了，背后的人动了手。
- 主角目标/关键选择：林迟要让陆砚深死心，别再拿移植和温棠绕回来。关键选择：陆砚深给的是一个体面的台阶——她搬回陆家老宅、有 24 小时护理，温棠回学校，他保证不碰温棠，表面上两全；林迟拒绝，因为那等于把两个人都放回陆家手里。代价：和陆砚深当面撕破，在他眼里坐实「为一个替身连命都不要」，换来他一句「我妈那边不会就这么算了」。
- 章首钩子：悬念对话开局 — 门一开，陆砚深看着门里的人愣了一下，先开口的是一句「……温棠？」
- 爽点：态度转变的前奏 + 打脸前奏——陆砚深第一眼没认出洗掉痣、穿回自己衣服的温棠（替身那层皮掉了）；林迟当面算账，三十万资助买一张脸一颗肾，嘴毒到底；高光台词「我不要任何人替我活」。往下看的理由：律师函。
- 本章禁止提前释放：
  - 律师函只露信封、抬头和「追讨资助款」几个字；不念正文，不出现违约金、任何数额以外的条款与金额（第6章）
  - 陆夫人不出场、不露她要联姻和「用完即弃」的算盘；陆砚深不知道、也不解释律师函
  - 不揭示、不暗示周敬夸大病情；陆砚深转述周敬的话不带任何指标数字（第8、11章）
  - 不出现「替身插足」流言（第6章）
  - 温棠不说「你会走吗」（第16章）；本章不新增碎片残留，「1」不变化

#### 内容概括（五段式）
- 起因：陆砚深从接送透析的司机那里知道温棠搬进了许知意的公寓，又从周敬那里听说许知意拒绝移植、只靠透析撑不了太久，昨晚发来「明天我过来」。
- 发展：开门的是温棠，陆砚深一时没认出她；进门后他压着火说明来意，转述周敬的话，提出让许知意搬回陆家老宅养病、温棠回学校、他保证不碰温棠。
- 转折：林迟拒绝；陆砚深终于问出口「为个替身，值吗？」林迟答「她叫温棠」，掐着指节把账摆上桌——三年三十万，买她照着描一颗痣、穿一身白裙子，最后再买一颗肾；她说「我不要任何人替我活」，温棠端着水站在厨房门口。
- 高潮：陆砚深沉默很久，没有降智发火，只说他会再想别的办法救她，起身时回头留下一句「我妈那边，不会就这么算了」；门关上，温棠走过来问「他说你撑不住，是真的吗？」林迟问系统，系统照旧「医学判断不在本系统服务范围内」，林迟笑着把话岔开。
- 结尾：下午门铃又响，律所的人递来一个牛皮纸信封，收件人写着「温棠」，请她在签收单上签字；温棠握着笔在签收栏上停了一下，写下自己的名字；林迟从她手里接过信封，看见抬头那行字：关于追讨资助款事宜的律师函。

#### 情节安排（多线）
- 主线推进：L01 从「虐点拆除后苦难值卡在 72，资助协议仍在」推到「陆家正面劝说失败，背后的人拿资助协议发了律师函」——下一单元 L1-02 的因果钩子落地。
- 辅线推进：L02 温棠在跟屁虫阶段第一次听见林迟替她说话（「她叫温棠」「我不要任何人替我活」），并第一次问林迟的身体（试探阶段的「察觉情绪」反向发生）；L05 林迟替温棠算「三十万买了什么」，账从笑点变成刀子；L04 温棠在签收单上写自己的名字（拿回名字的第一笔，底子）。
- 事件线 / 任务线：陆砚深上门（卡出他真心的让步方案——拒绝它要付关系代价）→ 林迟拒绝 → 「为个替身，值吗」 → 他退场并留话 → 律师函送到（卡出新的压力源，接第6章）。
- 感情线 / 关系线：试探阶段。温棠听见林迟替她说话，主动走过来问林迟的身体——这是她第一次反过来担心林迟；林迟用玩笑岔开，不交底。不写肢体亲密、不写心动。
- 逻辑线：司机和周敬把消息递给陆砚深 → 他上门劝、给出让步方案 → 林迟拒绝并说出底线 → 陆砚深退场、留下「我妈那边」 → 律师函送到；新问题：资助协议怎么追讨、追讨多少、温棠回不回得去学校。

#### 人物关系和出场顺序
- 出场顺序：温棠（开门）→ 陆砚深 → 林迟 → 周敬（只被转述）→ 司机（只被提及）→ 系统5468 → 陆夫人（只被提「我妈那边」）→ 律所送件人（路人）→ 律师函与签收单（关键物件）
- 人物关系变化：林迟×陆砚深：表面和解、她不接电话 → 当面撕破，他认定她为一个替身连命都不要，转身去找别的办法；陆砚深×温棠：只当替身 → 第一次没认出她、第一次听见别人叫她的名字，他没回应；林迟×温棠：温棠黏着她 → 温棠第一次反过来问她的身体；温棠×陆家：合约作废 → 陆家拿资助协议追了上来。
- 视角/信息差：读者和林迟都以为许知意确实病重、透析撑不了太久（周敬口径照旧）；陆砚深知不知道律师函，林迟和读者都不知道；读者和林迟知道 72 小时脱离，温棠不知道——她问「你撑不住吗」时，读者知道林迟还有另一件更瞒着她的事。
