## 细纲（第 3 章）

### 第 3 章：未婚夫不算家属
- 核心事件：第三天一早周敬派人来带温棠做术前检查，林迟明白口头拒绝只会被记录，改走正路——坐轮椅下到医务处，以受者本人身份书面拒绝活体移植、撤销排期，当场拆掉周敬「病人情绪不稳、得家属代签」的说法；又逼陆砚深让律师送来备份合约，亲笔写上作废，苦难值 100→72；她想就此和温棠划清界限，温棠却不走，说「你是第一个不要我替谁活的人」，系统随即提醒：任务完成，宿主 72 小时内脱离。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-01；单元第3拍「兑现」（合约作废、配型取消、苦难值第一次大跌），同时立「救了她就得走」期待债，不对劲等级第1格（依赖粘人）立起
- 目标情绪：读者从第2章「只挡了一天」的悬着，被一早又来带人的护士按回紧张；跟着林迟从嘴上硬顶换成白纸黑字，看周敬想拿「未婚夫代签」绕过她、被一句「我未婚，他不算家属」顶回去，再看陆砚深亲手在合约上写「作废」，一口气出到底；苦难值一下掉 28 点、报酬跳到 28 万，痛快里带财迷的笑；温棠那句话把痛快转成发软的温馨；最后系统一句「72 小时内脱离」把温馨切出一道口子。推进单元情绪引擎的「宿主不可替代的动作→兑现」：正主本人签字拒收、正主本人逼甲方作废，合约与配型从根上拆掉。
- 主角目标/关键选择：林迟要把配型和合约从根上拆掉，不再一天一天地挡。关键选择①：不再靠吵，改走医院的正式程序——用许知意本人的签字把移植彻底推掉，等于把这具身体「不换肾」写成定局，替原主做了一个收不回的决定；关键选择②：为了让陆砚深松手作废合约，她答应他按时透析、不再拔针乱跑，把自己拴在周敬的治疗方案上（第8章透析日承接）；关键选择③：事成后她按「救完就走」的规矩打算让温棠回学校、两人就此两清，被温棠一句话截住，她没再赶。
- 章首钩子：未完成动作开局 — 天刚亮，林迟盯着陪护床上的温棠，刚开口「昨晚那个香菜——」，门被敲响，护士推着轮椅进来：「温小姐，术前检查。」
- 爽点：目标达成（配型撤销、合约作废，第一个虐点拆掉）+ 打脸（周敬想拿「病人情绪不稳、需家属代签」绕开她，被「我未婚，他不算家属」当场顶回）+ 收获盘点（苦难值 100→72，报酬 0→28 万，林迟掐指节算账）；情绪落点在温棠的那句台词。
- 本章禁止提前释放：
  - 不揭示、不暗示周敬夸大病情；周敬被顶回时只写他笑着收手，不写他心虚（第11章）
  - 资助协议本章不动，不提资助款和违约金任何数额（第4、6章）；不出现律师函、流言
  - 72 小时只由系统对林迟一人说出，温棠不知道、林迟不告诉她；不出现「你会走吗」（第16章）
  - 林迟不说「我不要任何人替我活」这句原话（第5章对陆砚深说）；本章只给温棠说「你是第一个不要我替谁活的人」
  - 异常数值「1」不变化，系统不提；苦难值不降到 72 以下

#### 内容概括（五段式）
- 起因：昨天的拒绝只换来「检查改到明天、排期不动」；今天一早，周敬按排期派护士来带温棠。
- 发展：温棠习惯性地站起来要跟去，林迟叫她坐下；林迟意识到系统只「记录」口头拒绝，嘴上的「不换」挡不住第二次，便要来轮椅，带着温棠下到二楼医务处，要求以受者本人身份书面拒绝活体移植、撤销排期。
- 转折：周敬赶到医务处，笑着提出许小姐昏迷刚醒、情绪起伏大，这种决定应由家属陪同确认，陆先生可以代为签字；林迟当场顶回「我未婚，他不算家属；我清醒得很，要不要现场给我做个评估」，医务处主任按程序收下她的签字，排期撤销。
- 高潮：陆砚深赶来，林迟逼他作废备份合约——替身替的是她，她人就在这儿，医疗条款也已经没了用处；陆砚深咬牙要她答应按时透析、不再拔针，她答应；律师把备份送来，陆砚深亲笔写下「作废」签了名，林迟转手递给温棠「你的，收好」。面板跳数：苦难值 72，报酬 28 万。
- 结尾：回到病房，林迟收着笑跟温棠说「回学校去吧，以后离陆家远点，咱俩两清」；温棠坐在陪护床沿不动，把作废的合约夹进速写本，抬头说「你是第一个不要我替谁活的人」，鞋没穿、人没走；系统在这时弹出温馨提示：任务完成后，宿主将于 72 小时内脱离本世界——林迟正在掐的拇指停在了指节上。

#### 情节安排（多线）
- 主线推进：L01 从「受者口头拒收、配型排期与备份合约仍在」推到「受者书面拒绝、排期撤销，备份合约由甲方亲笔作废」——第一个虐点拆除，苦难值 100→72；剩下的 72 指向资助协议、死亡节点未过和温棠自己的心结。
- 辅线推进：L02 从「温棠第一次正眼看她、问她真的不要」推到「温棠拒绝两清、主动留下」，相识进入试探，不对劲第1格（依赖粘人）立起；L05 从「报酬 0 元、透析账」推到「报酬 28 万」，林迟当场掐指节算账；L03 只确认「1」没动（一笔带过）。
- 事件线 / 任务线：护士按排期来带人（卡出「口头拒绝不管用」，逼林迟换正式程序）→ 医务处书面拒绝 → 周敬「家属代签」卡住（卡出周敬不降智的手段，林迟用身份事实拆掉）→ 排期撤销 → 陆砚深与备份合约（卡出林迟要拿什么换：答应按时透析）→ 作废。
- 感情线 / 关系线：相识→试探入口。温棠半好感露头：拒绝离开、说出那句话；林迟这边没有心动动作，她想的是「救完就走」，第一次被这句话噎住。不写肢体亲密，不写林迟内心认栽。
- 逻辑线：口头拒绝只被记录、排期照走 → 林迟改走医务处书面程序、逼甲方作废备份 → 配型撤销、合约作废、苦难值掉到 72 → 林迟按规矩打算两清，温棠不走；新问题：任务一完成她就得在 72 小时内离开，而温棠刚说完那句话。

#### 人物关系和出场顺序
- 出场顺序：林迟 → 温棠（陪护床）→ 护士与轮椅（路人）→ 系统5468 → 医务处主任（路人）→ 受者拒绝移植声明（关键物件）→ 周敬 → 陆砚深 → 陆家律师（路人，第1章那位）与备份合约（关键物件）→ 任务面板（苦难值 72、报酬 28 万）→ 温棠的速写本 → 72 小时提示
- 人物关系变化：林迟×温棠：温棠开始怀疑「白月光是不是在演」→ 温棠拒绝两清、主动留在她身边；林迟×周敬：她驳回他的方案、他笑着记下 → 她当着医务处拆掉他的「家属代签」，他笑着收手；林迟×陆砚深：他认定她病糊涂了 → 他亲手作废合约，换来她答应按时透析，两人表面和解、心里各有疙瘩；温棠×陆砚深：未签约的替身乙方 → 合约作废，替身关系在纸面上了结（资助协议仍在陆家手里）。
- 视角/信息差：读者与林迟都以为许知意确实病重（周敬口径不动摇）；读者知道原书结局、苦难值和倒计时 39 天；本章起读者和林迟都知道「任务完成 72 小时内必须离开」，温棠不知道；读者看得见温棠速写本里已经夹着两张纸（第2章藏的那页 + 本章作废的合约），林迟只当她在收东西。
