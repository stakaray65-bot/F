## 细纲（第 14 章）

### 第 14 章：连画都是抄的
- 核心事件：新苗青年美术展终评当天，市美术馆报告厅公开评审，评委严立鸿拿出一沓打印截图，指温棠的《指节》抄袭网上一位画家两年前发布的作品，当众补一句「替身嘛，连画都是抄的」；林迟早有准备——她按简章第九条请评审会要求作者现场创作，又让温棠的同学抱来全部速写本，自己坐上侧台当模特、掐着指节让温棠当场画；四十分钟里温棠画完，过程稿一页页带日期摊开，林迟顺手指出那个「两年前」的发布账号上周才注册；评审会主任郑老师判抄袭不成立、严立鸿回避，温棠拿下金奖；苦难值 45→33；当晚有同学转话，松间画廊宋老板托人来问温棠愿不愿意签约，陆砚深发来消息：「后天，我想跟你谈婚期。」
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-03；单元第2拍「加压」＋第3拍「兑现」前半（画展抄袭污蔑→现场作画破局、温棠拿下画展）
- 目标情绪：读者从入场时的紧张被严立鸿那沓截图砸到谷底，「连画都是抄的」当着满场人说出来，温棠的脸一下白了，读者憋得发疼；林迟站起来念第九条，读者知道她早埋了这一手，心提起来；她自己坐上侧台当模特、嘴碎「按小时收费」，紧张里漏出笑；四十分钟温棠画得越来越稳，读者看着她从怯变成专注，一点点热起来；过程稿一页页带日期摊开、账号上周才注册，痛快；念出「金奖：温棠」，痛快到顶；宋老板托人来问签约，「替身画的东西也配挂墙」被第三方原样还回去，读者再笑一下；陆砚深那条消息把情绪收紧到后天。推进单元情绪引擎：本轮触发（抄袭污蔑）→宿主布局、温棠本人兑现。
- 主角目标/关键选择：林迟要让温棠在所有人面前用自己的手证明画是她的，而不是由别人替她证明。关键选择：她手里有许知意的身份和陆砚深的愧疚，一个电话就能让评审会给面子、压下指控；她选按规则走第九条，把证明交给温棠的手，自己只当模特。代价：现场作画四十分钟，温棠可能当场崩掉；她把温棠推上了最亮的地方，自己坐在旁边一动不能动。
- 章首钩子：未完成动作开局 — 严立鸿把一沓打印纸往评委席上一放，手指压在最上面那张：「这幅画——」话音没落，报告厅后排已经有人举起了手机。
- 爽点：能力碾压＋态度转变＋打脸（由第三方转述）——温棠当场画完、过程稿摊开、账号拆穿，严立鸿回避；金奖；宋启年托人求签约兑现第7章「替身画的东西也配挂墙」。收获盘点：苦难值 45→33，报酬 55万→67万；奖金 5 万归温棠。往下看的理由：后天，婚期，死亡节点前一天。
- 本章禁止提前释放：
  - 陆夫人不出场，只由林迟一句「替我问韩女士好」点到（她的最后一手落空）
  - 不说「你会走吗」，林迟不提 72 小时；温棠心结不解（苦难值卡在 33）
  - 婚约不解除，陆砚深只发消息（第15章）
  - 不新增碎片残留，异常数值不变（第17章）
  - 宋启年不出场，只被转述

#### 内容概括（五段式）
- 起因：第13章温棠以真名入围，评委名单里有陆夫人的旧识严立鸿；终评在第39天市美术馆当场公开评审，死亡节点倒计时 3 天。
- 发展：报告厅里入围者依次答辩，轮到温棠，严立鸿拿出打印截图：网上一位画家两年前发的作品，构图与《指节》几乎一样；他当众说「替身嘛，连画都是抄的」，后排有人举起手机，温棠站在台上，手指一点点发白。
- 转折：林迟从观众席站起来，念简章第九条，请评审会要求作者现场创作；严立鸿说「评审不是儿戏」，评审会主任郑老师说「画画的事，画了就知道」，准了；林迟招手，温棠的同学抱着一摞速写本上来；林迟自己坐上侧台的高凳，把右手搁在膝盖上：「模特按小时收费。」拇指掐上了指节。
- 高潮：温棠挽起袖子，用一支铅笔把头发别住，四十分钟，一笔没停；画完时报告厅很静。过程稿一页页摊开——从第12章那天清晨起，同一只手画了几十遍，每页右下角都有日期；林迟拿过严立鸿的截图，掏出手机点开那个发布账号的主页：「两年前发的图，账号上周才注册。」郑老师宣布：抄袭指控不成立，严立鸿回避本项评审；最后念到金奖：温棠。
- 结尾：面板跳两行，苦难值 33、报酬 670000 元；林迟对着散场的人群里严立鸿的背影说「替我问韩女士好」；晚上温棠的手机上，同学发来：「松间那个宋老板托我问问，你愿不愿意签约？」林迟凑过去看完：「这得加钱。」她自己的手机亮了，陆砚深：「后天，我想跟你谈婚期。」

#### 情节安排（多线）
- 主线推进：L01 从「陆家最后一手的影子」推到「最后一手落空，生计与名誉两项处境拆掉，苦难值 45→33」。
- 辅线推进：L04 从「入围」推到「现场作画破局、署名拿下金奖、画廊求签」——温棠拿回画笔和名字；L02 林迟当她的模特、坐在旁边四十分钟，温棠画的是她——从「看着她自己站」推到「她站上去时，她就在旁边」；L05 报酬 55万→67万，奖金 5 万。
- 事件线 / 任务线：答辩 → 抄袭指控（卡出流言的最后一刀）→ 第九条 → 现场作画（卡出温棠本人的能力）→ 过程稿 → 账号拆穿 → 判定 → 金奖 → 宋启年托人 → 陆砚深消息。
- 感情线 / 关系线：试探阶段。温棠画她的手，四十分钟里只抬头看她，不看台下；画完第一眼找的是林迟。不写肢体，不写心动独白。
- 逻辑线：陆夫人借旧识在终评上补一刀 → 林迟早记下第九条、备好过程稿 → 温棠当场画、过程稿与账号拆穿 → 指控不成立、金奖 → 名声与生计翻过来、画廊回头 → 婚事与死亡节点同时压到后天（新问题）。

#### 人物关系和出场顺序
- 出场顺序：严立鸿 → 打印截图（关键物件）→ 温棠 → 观众席与举手机的人（路人）→ 林迟 → 郑老师 → 温棠的同学（路人）→ 速写本与过程稿（关键物件）→ 发布账号主页（关键物件）→ 系统面板 → 同学转话（宋启年，只被转述）→ 陆砚深（消息）
- 人物关系变化：温棠×自己：怕被说「照着谁描」→ 当众证明画是她的、拿下金奖；严立鸿×温棠：替陆家补刀 → 被判回避；宋启年×温棠：「替身画的东西也配挂墙」→ 托人求签；林迟×温棠：她看着她站 → 她当她的模特、坐在她身边。
- 视角/信息差：读者与林迟知道严立鸿是陆夫人的旧识，场上其他人不知道；读者知道林迟第13章就记下了第九条，所以「早有准备」不是开挂；温棠不知道林迟查过那个账号。
