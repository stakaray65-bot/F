## 细纲（第 26 章）

### 第 26 章：慎刑司门口晕了个公主
- 核心事件：青梧拿着密信去东宫找太子谈交易：信给他，暗线她帮着查，换公主平安。元昭不信，把她送进慎刑司跟孙嬷嬷关在一处，看她俩会不会对上暗号。孙嬷嬷反咬她才是使团的人，青梧拿一笔账把这口咬顶了回去；正这时宁蘅走了两刻钟找到宫城北隅，一头栽在慎刑司门口，太子只好放人，临走接下了交易。回到漱玉轩，宁蘅睁开眼：「我没晕。那天打雷，我也不怕。」
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-05；单元第2拍「尝试与试探」；本卷 3/4 转折（动机反转揭示）
- 目标情绪：读者带着第25章「祭旗」的憋闷进来，看青梧当着太子把底牌一张张摊开，紧张；被送进慎刑司、孙嬷嬷反咬、拶子端上来，心提到嗓子眼；青梧拿账顶回去，松半口气；公主栽在门口，读者先当她又在粘人；最后那句「那天打雷，我也不怕」落下，读者把第21章装病、第25章怕雷全倒回去重看一遍——她不是在留人，是在护人，震惊里一股酸软。推进单元情绪引擎：被珍视的那一环翻面——宁蘅一直在用装可怜护着她。
- 主角目标/关键选择：林迟要拿密信给宁蘅换一道护身符。关键选择：密信是她手里唯一的筹码，交出去就什么都没了；不交，太子不会跟一个女官谈。她选择先交信、再谈条件，赌太子要的是暗线不是公主的命。代价：筹码离手，人被扔进慎刑司。
- 章首钩子：悬念对话开局 — 元昭转着扳指，第一句话是「你要拿什么换」，青梧没答，先把掌簿册的封皮拆开了。
- 爽点：态度转变 — 太子从「送你去慎刑司」到「交易本宫接了」；小打脸 — 孙嬷嬷反咬，被青梧一句「韦大人给了我几两」问住。往下看的理由：宁蘅的装可怜原来另有其意，她还装过几回、为什么。
- 本章禁止提前释放：
  - 宁蘅只说「他们要叫你走的时候，我才怕」，不解释她为什么知道、怎么知道；不写成她知道宿主会被伤害的真正原因
  - 孙嬷嬷只漏一句「娘娘那边……」就闭嘴，不出密旨内容（第27章到）
  - 不揭裴相与韦从简合谋、三箱是什么（第28章）
  - 太子的旧算盘（殿外加侍卫是护着）不交底（第30章）

#### 内容概括（五段式）
- 起因：第25章裴相当殿提「斩和亲公主祭旗」，苦难值回到78；青梧手里只有那封栽赃用的密信，能做主的只有太子。
- 发展：青梧递腰牌求见，元昭在东宫书房见她。她把密信摊上案，讲清来路：十七号箱夹层、两块铅砖、孙嬷嬷移进妆奁、「交公主亲启」公主从没拆过；再把界河的疑点摆出来；条件是护公主。元昭问「你凭什么让本宫信你不是那条线」，叫秦戈把她送进慎刑司，跟孙嬷嬷关一间。
- 转折：孙嬷嬷一见她就咬：「信是她放的，她才是使团的人。」管事太监端来拶子。青梧问孙嬷嬷：你账上韦大人给了你一千两，三笔日子都对得上宫门簿；咬我，那你说韦大人给了我几两、哪天给的。孙嬷嬷卡住，只漏一句「你以为有用？娘娘那边……」又闭了嘴。门外忽然乱了：公主晕在慎刑司门口。
- 高潮：隔间里一直在看的元昭走出来，看看地上的公主，又看看青梧，叫她送公主回去；擦肩时低声说「你家公主，比你会谈生意」，开出三条：漱玉轩换东宫亲卫、祭旗压到查明、大婚往后推；她给他那条线。苦难值78→74，系统说「本次未低于历史最低值，不计报酬」。
- 结尾：青梧把宁蘅背回东耳房放到床上，杏儿刚退出去，宁蘅就睁开了眼，眼里一点没糊：「我没晕。」停了一下，「那天打雷，我也不怕。」

#### 情节安排（多线）
- 主线推进：L01 拿到太子这一层保护——祭旗压到查明、大婚推后、东宫亲卫守轩；太子从压迫者转为可交易的一方。
- 辅线推进：L02 从装怕雷挤床推到门外装晕救人，并当着林迟亲口揭开（本卷动机反转）；L05 「降了不给钱」的账本笑点（历史最低值计件）。
- 事件线 / 任务线：求见 → 摊信谈条件 → 被疑 → 慎刑司试探 → 孙嬷嬷反咬、拶子 → 一笔账顶回 → 公主门口栽倒 → 太子放人、接下交易 → 回轩 → 「我没晕」。卡点：慎刑司这一关卡出了太子的结论——真暗线不会让公主晕在慎刑司门口。
- 感情线 / 关系线：试探阶段。宁蘅第一次在林迟面前卸下装：她护着林迟，林迟才知道。不写告白，不写心动独白；林迟的反应落在嘴碎和摸后颈上。
- 逻辑线：祭旗压顶 → 拿信找太子 → 太子疑她、扔进慎刑司试 → 孙嬷嬷反咬被账顶回、公主栽在门口 → 太子判定她不是线，接交易 → 新问题：宁蘅一直在护她，护了几回；太子到底要拿那条线做什么。

#### 人物关系和出场顺序
- 出场顺序：元昭 → 青梧（林迟）→ 掌簿册封皮、密信（关键物件）→ 东宫书房 → 秦戈 → 慎刑司 → 孙嬷嬷 → 管事太监（路人）、拶子（物件）→ 杏儿（路人）→ 宁蘅 → 系统面板 → 东耳房
- 人物关系变化：林迟×元昭：被盯上的女官 → 交易对手，有了三条约定；林迟×孙嬷嬷：已落网的对手 → 当面反咬又被顶回；林迟×宁蘅：她以为自己在护公主 → 发现公主一直在护她；宁蘅×元昭：人质 → 第一次让太子改了主意（太子心里记下）。
- 视角/信息差：读者第25章就看见「怕雷偏挑东宫来人那一刻」，本章由宁蘅一句话坐实；林迟此前只当她粘人。太子在隔间里看了全程，读者到他出来才知道。孙嬷嬷那句「娘娘那边」读者和林迟都不知道指什么。

#### 结尾设定和钩子
- 结尾设定：落在宁蘅睁着的那双清醒的眼睛和那三句话上；未解决问题：她还为她装过几回、她怎么知道该在什么时候怕；下一章推动力：交易生效后的平静能撑多久，孙嬷嬷说的「娘娘」是谁的人。
- 章尾钩子：突然揭示 — 「我没晕。那天打雷，我也不怕。」把前面两回装可怜整个翻面；期待度：强。下一章承接：第27章十八天后南楚来人。
