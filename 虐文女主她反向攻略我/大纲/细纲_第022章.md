## 细纲（第 22 章）

### 第 22 章：她梦见有人这么说
- 核心事件：宁蘅「病好了」，白日坐在廊下画院里那株不开花的西府海棠，凭记忆画了满枝花；她说自己从小被要求「像」皇后那个亲生的女儿，连和亲都是替那位公主来的，又说「梦里有人说我不用像谁」——青梧手里的茶盏一晃。傍晚詹事府叫青梧去对嫁妆入库册，一去两个时辰；回程亥时三刻面板跳到 99。她回到漱玉轩先去西厢，十七号箱夹层空了；守夜的小宫女说，亥时三刻孙嬷嬷进内寝添过香。她趁宁蘅睡熟摸她的妆奁，底层夹层里，正是那封信。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-04；单元第4拍「转向」（宁蘅画海棠＝本单元内转折：后一个世界的女主「记得」前一个世界；同夜密信失踪，宿主用苦难值波动锁定孙嬷嬷）
- 目标情绪：读者先在廊下画花的安静里喘口气，宁蘅说起「像谁」，读者想起温棠，心里一揪；「梦里有人说我不用像谁」一出，读者全身一激灵——林迟在世界1 说过这句话，她却只会想「她怎么知道」；傍晚被支走、亥时三刻数字跳，紧张拉回来；夹层空了，心一沉；小宫女一句「孙嬷嬷进去添过香」，时辰对上，读者跟着「抓到了」；最后信躺在公主枕边的妆奁里，压力推到本单元最高。推进单元情绪引擎：缺口维持（陪嫁里有暗桩，信越挪越近）＋宿主金手指新用法第一次真正派上用场。
- 主角目标/关键选择：林迟要盯住那封信，找出是谁放的。关键选择：詹事府来叫人，她可以推说公主离不得人；去了，轩里就空了；她选择去——留出空当，看谁会动那封信，用苦难值记时辰。代价：她赌赢了，可信被挪到了公主的妆奁里，离公主只差一个枕头。
- 章首钩子：意象预示 — 院里那株西府海棠八月只结果、不开花，宁蘅却在纸上画了满枝的花。
- 爽点：慧眼识真——苦难值跳数的时辰、小宫女的证词、谁在内寝，三样一对，锁定孙嬷嬷；往下看的理由：信现在离公主只隔一个枕头；宁蘅那句话是从哪来的。
- 本章禁止提前释放：
  - 宁蘅只「梦见」一句话，不知道温棠是谁、不知道宿主从哪来；林迟只觉得「她怎么知道」，不得出「同一个人」的结论
  - 不提南楚皇后密旨（第27章）；宁蘅只说和亲是替皇后亲女来的
  - 孙嬷嬷的私账本章不出现（第23章）；孙嬷嬷背后是谁不揭
  - 宁蘅不露她已看穿布局（第23章）
  - 不写掐指节的跨世界呼应（第25章）

#### 内容概括（五段式）
- 起因：第21章青梧把密信放回当饵；宁蘅第二天就不「病」了。
- 发展：宁蘅坐在廊下画海棠，院里那株只挂着青果子，她画的却是满枝的花。青梧凑过去看，嘴上算账「画个花能卖几两」，宁蘅不理她，低着头说：从小嬷嬷就要她学皇后那个亲生的女儿走路说话，和亲原本也该是那位去，临行换成了她。她顿了顿：「不过我梦见过一回，梦里有人说，我不用像谁。」青梧手里的茶盏一晃，茶泼了半盏——那句话她说过，在另一个地方，对另一个人；她想不通，只能问「谁说的」，宁蘅摇头：「看不清脸。」
- 转折：傍晚詹事府王管事来叫青梧去对嫁妆入库册，宁蘅拽着她袖子说「早点回来」，这回没装病；她去了，一对就是两个时辰。回程走到半道，亥时三刻，面板：【当前苦难值：99】，处境项还是「涉嫌通敌风险上升」。
- 高潮：她一进漱玉轩先去西厢，撬开十七号箱底板——夹层空了。她找守夜的小宫女小满和杏儿，问亥时前后谁进过内寝；两人一对：「亥时三刻，孙嬷嬷进去添过一回香。」时辰和数字跳的那一下一分不差。
- 结尾：她等宁蘅睡熟，摸到床头那只描金妆奁，一层层抽开，最底下那层的底板一按就松，夹层里，火漆纹一模一样——那封信，离公主的枕头不到一尺。

#### 情节安排（多线）
- 主线推进：L01 锁定暗桩孙嬷嬷；密信被挪进公主妆奁，原书「搜宫搜出密信」的局摆好了，苦难值 97→99。
- 辅线推进：L03 碎片残留加码——宁蘅画海棠、说「梦里有人说我不用像谁」（F14 埋；回声第16章林迟原话）；L02 宁蘅不装病了，只拽着袖子说「早点回来」；宁蘅的心结第一次说出口（替皇后亲女和亲、从小被要求像谁）。
- 事件线 / 任务线：画海棠 → 「像谁」→ 「梦里有人说我不用像谁」→ 被叫去对册 → 亥时三刻 99 → 夹层空了 → 小宫女证词 → 锁定孙嬷嬷 → 妆奁夹层里的信。
- 感情线 / 关系线：试探阶段。宁蘅把心结交出一角（像谁），林迟被那句梦话撞了一下，慌，摸后颈；不越过「说不清」。
- 逻辑线：留出空当 → 有人趁空挪信 → 苦难值记下时辰 → 证词对上 → 锁定孙嬷嬷、找到信的新位置 → 新问题：东宫什么时候来搜；怎么把这封信变成孙嬷嬷自己的罪证。

#### 人物关系和出场顺序
- 出场顺序：西府海棠（意象）→ 宁蘅（画画）→ 青梧（林迟）→ 茶盏 → 王管事（路人）→ 詹事府 → 系统面板 → 西厢库房、十七号箱（关键物件）→ 小满、杏儿（路人小宫女）→ 孙嬷嬷（被转述）→ 描金妆奁（关键物件）→ 密信
- 人物关系变化：林迟×宁蘅：公主黏她 → 公主把心结交出一角，一句梦话让林迟慌了；林迟×孙嬷嬷：怀疑 → 锁定；宁蘅×南楚皇后：读者第一次知道她是替人来的弃子。
- 视角/信息差：读者知道「不用像谁」是第16章林迟对温棠说的原话，林迟也想到了，但只到「她怎么知道」；读者与林迟知道信在妆奁里、是孙嬷嬷挪的，孙嬷嬷不知道她已经被盯上；宁蘅知道多少，本章不交底。
