## 细纲（第 34 章）

### 第 34 章：交接清单写到第三页
- 核心事件：脱离倒计时一路往下跳，林迟在临渡驿偏间狂写交接清单留给醒来的青梧：哪本账在哪、秦戈是谁、月例几两、公主自己会算账别替她算；写到「你醒来会觉得像做了一场梦」，系统提示「该表述接近违规边缘」，她划掉改成「你病了一场」。十月初一临渡互市开市，南楚茶船靠岸、北燕马队下滩，宁蘅拨算盘抽下第一笔税，秦戈替太子送来一方「互市主事」印。傍晚两人坐在驿楼栏杆上，宁蘅说：「我在这儿一天，就管我自己一天。」倒计时归零，后颈像钉进一根钉子，这回疼得更久，手抖得停不下来。系统空间里：世界2报酬入账、结算照旧含糊；异常数值从6跳到13，乱码里又解出一个「替」字；她问那是什么，系统「该数值不归本系统监测」又答得太快。她第一次追问：「你是不是有事瞒我？」系统：「该问题不在本系统服务范围内。温馨提示：建议宿主休整。」后颈的疼没散。
- 字数目标：2500 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-06；单元第4拍「72小时与离开」
- 目标情绪：读者从河滩的火里进来，看林迟一边嫌「史上最亏的一单加班」一边狂写清单，笑里带酸；违规提示一跳，跟着紧一下；开市那一幕热闹、宁蘅抽下第一笔税，读者替她骄傲；栏杆上她把「管你一天」改成「管我自己一天」，刀从温柔里进去；倒计时归零的疼比上回更狠，读者揪心；系统空间里「替」字、答得太快、第一次追问，疑团冒头——不安压过了到账的痛快。推进单元情绪引擎：兑现后的代价——救了她就得走，第二次比第一次更难受；卷级：宿主第一次问系统瞒她什么。
- 主角目标/关键选择：林迟要在72小时里把宁蘅和醒来的青梧都安顿好，再走。关键选择：交接清单里她想把这一个多月的事原原本本写给原主——写得越清楚，原主越好接手；可写过线就是违规。她选择在线内写到最满，碰到提示就划掉，不冒险；最后几个时辰她不再写，去陪宁蘅坐着。代价：清单只能写「病了一场」，很多事原主要自己摸。
- 章首钩子：倒计时开局 — 【脱离倒计时：47:12:05】，她面前已经铺开三张写满的纸，第四张刚蘸上墨。
- 爽点：收获盘点（世界2报酬82万入账）+ 目标达成（互市开市，宁蘅抽下第一笔税、拿到主事印）。往下看的理由：「替」字是什么意思；系统到底瞒了什么；疼为什么不散。
- 本章禁止提前释放：
  - 系统不回答追问；不出现救生舱、碎片、沈渡之名；「替」字林迟不懂，只盯着看
  - 异常数值只解出「替」一个字，不得与「活」连成有意义的句子，不出现「一起」二字
  - 后颈疼只读作穿越反应加重，不写代价真相
  - 宁蘅不知道「怎么走、几时走」，只知道「会走」；不写告别哭戏

#### 内容概括（五段式）
- 起因：第33章任务完成，【脱离倒计时】常驻；她答应了宁蘅「看一眼开市」，也得给醒来的原主留条后路。
- 发展：倒计时四十七个时辰，林迟在偏间写交接清单：哪本账在哪个箱子、漱玉轩的钥匙给了谁、秦戈是东宫卫率、你月例六两、公主自己会算账别替她算、公主不吃什么你别问为什么。写到「你醒来会觉得像做了一场梦」，面板一跳：「温馨提示：该表述接近违规边缘。」她划掉，改成「你病了一场」，嘀咕这是史上最亏的一单加班。宁蘅进来替她磨墨，不问，只掐着指节数她写了几页。
- 转折：十月初一临渡互市开市，南楚茶船靠岸、北燕马队下滩，宁蘅坐在棚下拨算盘，抽下第一笔税写进新账第一页；秦戈替太子送来一方「互市主事」印。林迟站在驿楼上远远看，面板18不动、报酬82万不动，她头一回没心思算。
- 高潮：傍晚两人坐在驿楼栏杆上，宁蘅握着她的手，拇指一节一节掐她的指节数天黑。她说：「我在这儿一天，就管我自己一天。」倒计时归零，后颈像钉进一根钉子，疼得比上回久，右手抖得握不住，那只手从宁蘅手里抖出去——眼前一白。
- 结尾：系统空间。【脱离中】【世界2报酬：820000 元，已计入宿主账户】，问兑付，系统照旧「最终兑付以全部任务结算为准」。角落异常数值从6跳到13，乱码里又解出一个字：「替」，跟「活」隔着一串乱码。她问，系统：「该数值不归本系统监测。」答得太快。她按着后颈：「你是不是有事瞒我？」系统停了一下：「该问题不在本系统服务范围内。温馨提示：建议宿主休整。」后颈的疼一直没散。

#### 情节安排（多线）
- 主线推进：L01 世界2 收束——脱离，报酬入账。
- 辅线推进：L05 交接清单与违规边缘提示、82万入账；L04 互市开市、主事印；L02 第二次告别（「管我自己一天」回声第25章）；L03 后颈疼加重（F009）、异常数值第二次变化（F001：6→13，解出「替」）、「不归本系统监测」又答得太快（F002），系统三处破绽（结算含糊、催休息、答得太快）凑齐，林迟第一次追问。
- 事件线 / 任务线：倒计时 → 写清单 → 违规边缘提示 → 划掉改写 → 磨墨数页 → 开市、第一笔税、主事印 → 栏杆 → 「管我自己一天」→ 归零、剧痛 → 系统空间 → 入账、含糊 → 「替」→ 答得太快 → 追问 → 催休整 → 疼不散。
- 感情线 / 关系线：试探阶段的第二次断开；她握着她的手掐指节数天黑，是本卷最近的一回接触。不写告白、不写吻别。
- 逻辑线：任务完成必须走 → 留清单给原主、在线内写满 → 看完开市 → 归零脱离、疼加重 → 异常数值变化、系统答得太快 → 林迟第一次起疑并追问 → 系统拒答催休整 → 新问题（交卷2）：系统瞒了什么；「替」是什么。

#### 人物关系和出场顺序
- 出场顺序：面板倒计时 → 青梧（林迟）→ 交接清单（关键物件）→ 系统提示 → 宁蘅 → 墨、砚 → 临渡互市（场景）、南楚茶船、北燕马队 → 新账第一页（物件）→ 秦戈 → 「互市主事」印（关键物件）→ 驿楼栏杆 → 系统空间 → 异常数值（关键物件）→ 系统5468
- 人物关系变化：林迟×宁蘅：答应看一眼开市的人 → 看完了，在她手里走了；宁蘅×自己：「管你一天」的被管者 → 「管我自己一天」；林迟×系统：一本正经的雇主 → 她第一次觉得它在瞒她。
- 视角/信息差：读者知道「替」与「活」最终属于一句话、疼是代价，林迟不知道；宁蘅不知道林迟以什么方式走。本章最后一场切到系统空间，仍是林迟视角。
