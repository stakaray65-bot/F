## 细纲（第 23 章）

### 第 23 章：我的脚没崴
- 核心事件：青梧拿着和约第九款去礼部偏衙，抄下礼部入库单，再对自己掌簿册里的南楚礼单——礼单一百二十八箱，入库单一百三十一箱，主事说多出的三箱是「使团自理」的礼器，她记下了。回轩后她在孙嬷嬷针线笸箩的夹板底下翻出一本私账：七月十九、七月廿七、八月初二，三笔「收韦大人银」，共一千两。她没毁信，选择调包——把私账塞进妆奁夹层，密信收进自己掌簿册的封皮里；正换到一半，孙嬷嬷回来要进内寝取妆奁给公主梳头，院子里宁蘅「哎呀」一声崴了脚，非要嬷嬷扶她去净房。苦难值 99→93，报酬只多了一万。夜里宁蘅背对着她小声说：「姑姑，下次换东西，先跟我说一声。」又补一句：「我的脚没崴。」
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-04；单元第5拍「决定性行动」（抄嫁妆清单与礼部入库单、调包；宁蘅看穿布局、配合演戏）
- 目标情绪：读者先跟着青梧在礼部抄账的利落里过瘾，「另三箱，使团自理」一闪而过，细心的读者会记住；翻出私账那一下，痛快——证据有了；调包到一半孙嬷嬷回来，心跳到嗓子眼；宁蘅那声「哎呀」救场，读者先当是巧合；跌了六点只给一万，林迟跳脚，笑一下；夜里「下次换东西，先跟我说一声」——读者和林迟一起被掉了马甲，原来这公主全看见了，惊又甜。推进单元情绪引擎：宿主不可替代的动作（清单件数、箱子分量一笔笔对出来、调包）落地；宁蘅的聪明第一次露底，是她自己的选择。
- 主角目标/关键选择：林迟要抢在孙嬷嬷告发之前，把公主枕边那封信变成孙嬷嬷自己的罪证。关键选择：毁掉密信最安全，东宫来搜搜不出东西就完了——可孙嬷嬷还在，会再栽一回；调包能让来搜的人搜出孙嬷嬷自己的账，一次拔掉暗桩，但万一被撞破，她就是偷换证物的那个人。她选择调包，并把密信留在自己手里当筹码。代价：她自己揣着一封能要命的信；险些被孙嬷嬷当场撞破。
- 章首钩子：未完成动作开局 — 礼部偏衙里，青梧的算盘珠子拨到一半停住：入库单最末一行，比她册子上多出三箱。
- 爽点：慧眼识真＋掉马甲——私账到手、调包完成；宁蘅「我的脚没崴」把她自己的聪明亮出来；小笑点：跌六点只计一万。往下看的理由：孙嬷嬷连夜往东宫去了，搜宫就在眼前。
- 本章禁止提前释放：
  - 「另三箱，使团自理」只记下、不深究，不揭军械与裴相（第28章）
  - 私账只写收韦大人银，不写韦从简与裴相的关系
  - 宁蘅装可怜的真实动机不揭（第26章）；她只说「先跟我说一声」，不说她知道多少、为什么帮
  - 东宫本章不来搜（第24章）
  - 不揭太子早知公主可能无辜（第30章）

#### 内容概括（五段式）
- 起因：第22章信被挪进公主妆奁，告发随时会来；青梧得在东宫来搜之前动手。
- 发展：一早她拿和约第九款「双方各执入库单一份」去礼部偏衙，主事嫌麻烦，她顺手帮他把漱玉轩份例那笔烂账理清了，主事这才让她抄。她把入库单抄完，对自己册子上的礼单：礼单一百二十八箱，入库单一百三十一箱，末行注「另三箱，使团自理，不入公主库」；主事说是使团自带的礼器，她点头，在两份抄件上各画了个圈。回到轩里，趁孙嬷嬷陪公主去小佛堂，她翻孙嬷嬷屋里的针线笸箩，夹板底下一本薄册：「七月十九，收韦大人银五百两」「七月廿七，收二百两」「八月初二，收三百两」。
- 转折：毁信，还是调包？她选调包——把私账塞进妆奁夹层，把密信收进自己掌簿册的双层封皮里。正把夹层底板按回去，院门响了，孙嬷嬷先一步回来，径直往内寝走：「公主要梳头，我来取妆奁。」
- 高潮：院子里宁蘅「哎呀」一声，坐在台阶下捂着脚踝，非要孙嬷嬷扶她去净房、谁都不许换；孙嬷嬷只好折回去。青梧把妆奁原样摆好，退出内寝。面板：【当前苦难值：93】【当前报酬：70000 元】——跌了六点只多一万，系统：「报酬按历史最低值计件。」她差点在院子里骂出声。
- 结尾：夜里宁蘅背对着她，声音很轻：「姑姑，下次换东西，先跟我说一声。」青梧一下坐直了。宁蘅翻了个身，又补一句：「我的脚没崴。」窗外，后罩房的门吱呀一声，孙嬷嬷的身影出了漱玉轩，往东宫那边去了。

#### 情节安排（多线）
- 主线推进：L01 拆「细作败露」的道具第一层——调包完成，密信转到宿主手里，私账进了妆奁；苦难值 99→93。
- 辅线推进：L02 从装病留人推到配合演戏——宁蘅看穿布局、主动替她拖住孙嬷嬷，并当面点破，聪明第一次露底（她自己的选择）；L05 按历史最低值计件的规矩露面（报酬 6 万→7 万）；F15 埋下：宿主抄下的嫁妆清单与礼部入库单，「另三箱，使团自理」。
- 事件线 / 任务线：礼部抄单（被主事卡住 → 帮他理账换来抄件）→ 一百二十八对一百三十一 → 私账 → 毁信还是调包 → 调包 → 孙嬷嬷回来 → 宁蘅崴脚救场 → 苦难值 93 → 「先跟我说一声」→ 孙嬷嬷去东宫。
- 感情线 / 关系线：试探阶段的一次「互相给回报」：她替公主扛险，公主替她拖人；宁蘅点破时不撒娇不邀功，林迟这回不是慢半拍，是当场被看穿。
- 逻辑线：告发将至 → 抄单、找私账 → 调包、密信留手里 → 孙嬷嬷险些撞破，宁蘅拖住 → 风险转移、苦难值降 → 新问题：孙嬷嬷去告发了，东宫会怎么搜；宁蘅到底知道多少。

#### 人物关系和出场顺序
- 出场顺序：青梧（林迟）→ 礼部偏衙、礼部主事（路人）→ 入库单与礼单（关键物件）→ 漱玉轩 → 孙嬷嬷的针线笸箩、私账（关键物件）→ 妆奁、密信（关键物件）→ 掌簿册封皮 → 孙嬷嬷 → 宁蘅 → 系统面板 → 系统5468 → 孙嬷嬷的背影
- 人物关系变化：林迟×宁蘅：她护着公主 → 公主也护着她，并且把话挑明——两人从此在一条船上；林迟×孙嬷嬷：锁定 → 证据到手，局已调换；林迟×礼部主事：被卡 → 拿抄件。
- 视角/信息差：读者与林迟知道私账进了妆奁、密信在青梧手里；孙嬷嬷不知道，以为信还在；宁蘅知道「换了东西」，换了什么、她知道到哪一步，本章不交底；读者看见「另三箱，使团自理」，林迟记下了但当它是使团的事。
