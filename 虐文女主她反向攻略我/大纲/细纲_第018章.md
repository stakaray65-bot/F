## 细纲（第 18 章）

### 第 18 章：醒来的人吃香菜
- 核心事件：（温棠视角）那只手从她手里抖出去之后，许知意靠在沙发上睡沉了；温棠守到天亮，醒来的人看着她问「你是谁，怎么在我家」；她看见抽屉里那页备忘，认得是自己的字，却不记得写过；早饭温棠照资料给她的碗里撒了香菜，另一碗下意识挑得干干净净，却不知道该端给谁；温棠这才明白：沙发上这个才是许知意，那个人不是她——可那个人是谁，她只记得一只掐指节的手、一句「这得加钱」，想不起脸。她把白色小皮鞋收进许知意的鞋柜，穿着自己的旧帆布鞋搬走；一个月后在新租的单间里，凭记忆画下那只手。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 单元ID/位置：L1-03；单元第6拍「女主视角」；世界1 最后一章
- 目标情绪：读者从第17章那个「活」字和空了的手进来，换到温棠这边，先是守夜的不安；许知意一句「你是谁」，读者知道答案、温棠不知道，刀从信息差里进去；香菜那一下，读者比温棠先懂；「那个人不是她」落地时，读者心里一酸——她记得所有事，唯独记不住那个人；收鞋、换鞋，是温棠自己往前走；最后画那只手、拇指在自己指节上掐出一块白印子，悲伤里留一口温。推进单元情绪引擎：兑现之后的代价落在女主那边——被珍视过，却说不清被谁。
- 主角目标/关键选择：（本章主视角为温棠）温棠要弄明白那个人去哪了，也要让自己接着活下去。关键选择：许知意醒来客气地说「你住到搬家为止」，她可以留下来等——等那个人哪天再「回来」；她选择当天就搬走，把白色小皮鞋留在许知意的鞋柜里，穿自己的鞋出门。代价：她亲手放下了最后一样能让她「像」的东西，也放下了在这里等的念头。
- 章首钩子：未完成动作开局 — 温棠的拇指还停在一个指节上，可那只手已经不在她手里了；她低头看自己空着的手，数到一半的那一分钟没数完。
- 爽点：无显性爽点，功能是世界1 收刀与女主视角兑付「救了她就得走」；往下看的理由：温棠记得的那几样东西，下一个世界的「她」也会记得吗；「那个人」换了个地方。
- 本章禁止提前释放：
  - 温棠视角只写她记得的零星片段（掐指节的手、「这得加钱」、碗里不能有香菜、「你不用像谁」），不出现青梅、未来、救生舱、沈渡之名
  - 温棠不知道系统、不知道穿越；不得出「有另一个人住在她身体里」的明确结论，只到「那个人不是她」「说不清」
  - 不写林迟视角，不切系统空间（第19章开头）
  - 许知意不知道这四十多天发生过什么，只当做了一场长梦；不写她记起任何片段
  - 不写碎片收走的含义

#### 内容概括（五段式）
- 起因：第17章倒计时归零，那只手在温棠手里猛地一抖、滑了出去；身边的人靠着沙发睡沉了，怎么叫都不醒。
- 发展：温棠守了一夜，把毯子给她盖好，自己坐在地铺上，鞋尖照旧朝着她。天亮时沙发上的人醒了，揉着眼睛坐起来，两手搁在膝上，眉心压出一道竖纹，看见她吓了一跳：「你是谁？怎么在我家？」温棠张了张嘴，只说「我是温棠」。许知意在抽屉里找到那页备忘，一行一行读，「这是我的字……可我不记得写过」，读到「温棠救过你的命」，抬头看她，客客气气：「我好像睡了很久，做了个很长的梦。你先住着，住到找到房子为止。」
- 转折：温棠去厨房煮粥，照替身资料给许知意那碗撒了一把香菜，另一碗下意识一片一片挑干净——挑完才停住手：这碗端给谁？许知意端起那碗香菜的，喝了一口，笑：「你怎么知道我爱吃这个。」温棠看着她拿勺子的手——不掐指节，不算账——心里冒出那句陆砚深说过的话，方向反了过来：她才是许知意。那个人，不是她。
- 高潮：温棠拼命去想那个人的脸，想出来的都是许知意的脸，可那张脸不会眯着眼算房租，不会一边说「这得加钱」一边把她按住；她记得每一件事，那个人在里头却只剩一只掐指节的手、一句「这得加钱」、碗里不能有香菜、一句「你不用像谁，也能被留下」。
- 结尾：她把白色小皮鞋鞋尖朝着沙发最后摆了一次，收进许知意的鞋柜，穿着自己的旧帆布鞋搬走了。一个月后，美院后街那间单间里，她凭记忆画一只手：手背瘦，拇指抵在食指第二个指节上，指节中间留一小块白；画完她把自己的右手抬起来，拇指往食指节上一按，掐出一块白印子，看了很久。

#### 情节安排（多线）
- 主线推进：L01 世界1 收束——宿主已离开，原主醒来，女主活着、往自己的路上走。
- 辅线推进：L03 女主视角零星片段第一次兑现（F08 回收：温棠画那只掐指节的手）；L02 第一次告别的余波——「救了她就得走」第一次兑付完成；L04 温棠搬进自己的房间、接着画画。
- 事件线 / 任务线：守夜 → 许知意醒来「你是谁」→ 备忘 → 「你先住着」→ 香菜 → 「那个人不是她」→ 想不起脸 → 收鞋换鞋搬走 → 一个月后画手。
- 感情线 / 关系线：试探阶段的一次断开。温棠对「那个人」的怀念说不清对象；不写告白、不写「我喜欢她」。
- 逻辑线：宿主脱离 → 原主醒来不认识她 → 温棠从香菜与那双手认出「不是她」→ 她选择不等、自己走 → 结果：她活着、画着，记得一个说不清的人（新问题交给下一世界：那个人去了哪儿）。

#### 人物关系和出场顺序
- 出场顺序：温棠（视角）→ 空了的手 → 沙发上睡着的许知意 → 毯子、地铺、白色小皮鞋 → 许知意醒来 → 书桌抽屉、备忘（关键物件）→ 厨房、两碗粥、香菜（关键物件）→ 冰箱便利贴 → 鞋柜 → 旧帆布鞋 → 美院后街单间 → 画架、那只手的画（关键物件）
- 人物关系变化：温棠×许知意：长得像的两个人 → 互不认识的陌生人，客气地道别；温棠×「那个人」：天天在一起 → 只剩几样记得的东西，说不清是谁；温棠×自己：照着谁活的替身 → 穿自己的鞋、住自己的门牌号、画自己想画的。
- 视角/信息差：读者知道「那个人」是林迟、知道她去了下一个世界；温棠不知道，只知道「不是她」；许知意什么都不知道；读者看得出温棠记不住那张脸不是因为忘了，而是那张脸从来就不是那个人的。

#### 结尾设定和钩子
- 结尾设定：落在温棠自己指节上那块白印子；未解决问题：那个人是谁、去了哪；下一章推动力：切回林迟——她在一个白茫茫的地方醒来，后颈还在疼。
- 章尾钩子：回声钩子 — 第12章开篇是林迟看温棠画她的手、自己拇指一搭「连白印子都对得上」，本章章尾是温棠画完、拿自己的拇指掐出那块白印子，动作同一个，掐的人换了；期待度：中。下一章承接：第19章系统空间结算。
